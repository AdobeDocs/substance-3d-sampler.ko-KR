# 버전 4.5

<b>Substance 3D Sampler 4.5</b>에서는 타사 앱에 대한 보내기 기능을 도입했습니다.

수동 내보내기 및 가져오기 프로세스를 거치지 않고 시간을 절약할 수 있도록 Sampler에서 한 번의 클릭으로 에셋을 타사 애플리케이션으로 보낼 수 있습니다.

추가 정보 [여기](../pipeline-and-integrations/substance-connector.md).

*출시일: 2024년 7월 10일*

![](../assets/connector-whatsnew.jpg)

## 릴리스 정보

*(릴리스: 2024년 7월 18일)*

<b>추가됨</b>:

* [상호 운용성] UE5, Blender, Maya, 3DsMax Unity로 재질 보내기
* [콘텐츠] 새로운 텍스처 생성기 범주 - 그레이디언트
* [콘텐츠] HDRI 도구 - 새 환경 회전 필터

<b>고정:</b>

* [노출된 매개 변수] .sbsar 입력 값을 노출해도 작동하지 않음
* [레이어] 기본 색상이 회색 음영 이미지로 빨간색으로 변합니다
* [렌더링] 색상 채널에 사용된 회색 음영 이미지의 색상 공간이 잘못되었습니다
* [스크립팅] 내보내기 사전 설정을 사용하면 경우에 따라 원하는 채널을 내보내지 못합니다
* [내용] Dirt - 이미지 위에 Dirt 필터를 적용하면 검정 표준이 생성됩니다.
* [내용] 엠보스 - 엠보스 필터에서 패턴의 비율이 0과 1 사이의 선형이 아닙니다
* [내용] 타일링 효과 적용 - 일반 및 Height 일관성 개선
