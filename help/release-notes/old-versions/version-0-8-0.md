# 버전 0.8.0

**추가됨:**

* [리소스] 로컬 디스크의 재질 폴더를 연결하고 미러링합니다.
* [리소스] 재질 폴더 및 하위 폴더를 찾습니다.
* [리소스] 전체 화면에서 리소스를 확인하려면 별도의 창에서 재질 리소스 패널을 분리합니다
* [리소스] 폴더 및 하위 폴더 탐색을 지원하는 새 리소스 패널 레이아웃
* [Resources] Breadcrum을 사용하여 폴더 탐색
* [리소스] 마우스 오른쪽 버튼을 클릭하여 액세스할 수 있는 동기화 옵션을 사용하여 로컬 폴더를 강제로 동기화합니다.
* [리소스] 마우스 오른쪽 버튼을 클릭하여 액세스할 수 있는 연결 해제 옵션으로 로컬 폴더의 연결을 해제합니다
* [관리] Substance 파일의 포함된 태그 표시
* [관리] 재질에 대한 태그를 추가, 편집 및 삭제합니다
* [관리] 재질 평가
* [레이어] 파노라마 출력 지원
* [레이어] 이미지 가져오기 레이어에서 이미지 입력을 삭제할 수 있습니다
* [레이어] 새로 추가된 레이어의 자동 선택
* [레이어] 레이어 삭제 후 아래 레이어가 자동으로 선택됩니다
* [UX] 다른 실습실로 전환할 때 왼쪽 패널을 계속 표시
* [UX] 비어 있지 않은 레이어 스택에서 이미지를 가져올 때 기본 레이어를 만들거나 Material Workflow 팝업을 열지 마십시오
* [UI] 새 텍스트 필드 스타일
* [UI] 새로운 SearchBox 스타일
* [UI] 새 패널 헤더 스타일
* [UI] 새로운 사용 중 표시기 스타일
* [UI] 새 레이어 스택 배경 스타일
* [UI] Adobe Clean 글꼴 사용
* [UI] 색상 입력 매개 변수의 스포이드 아이콘 자리 표시자를 제거합니다.
* [성능] 사용 중 표시기 최적화
* [콘텐츠] 새로운 패턴 생성기 필터
* [내용] 새로운 흐림 효과 필터

**고정:**

* [영감] 10개 이상의 색상을 사용할 때 충돌 문제 수정
* [2D 보기] 2D 보기의 채널 목록에서 스크롤 막대를 수정합니다.
* [뷰어] 2의 전원이 아닌 환경 맵을 가져올 때 발생하는 충돌 문제 수정
* [콘텐츠] 엠보싱 및 천공 필터의 사용자 정의 패턴에 대한 PNG 가져오기 수정
* [내보내기] 정상 및 채널당 16비트 Height 내보내기 수정
* 이름이 같은 두 개의 사전 설정이 있는 재질을 가져올 때 무한 루프 수정
* 기본 재질 레이어에서 긴 파일 경로 표시 수정

**알려진 문제:**

* 하나의 재질에 여러 개의 흐림 효과를 사용하는 것은 권장되지 않습니다
* 구형 NVIDIA 드라이버에서 Delighter 충돌(400.x 미만)
* Delighter 단계의 빠른 가시성 전환은 권장하지 않습니다
* 이미지 가져오기 레이어의 [속성] 패널에 TIF 이미지가 표시되지 않습니다
* 슬라이더에서 특정 값을 입력할 때 혼수 또는 점을 무시할 수 있습니다
* Height에 표준 필터가 MacOS에서 충돌할 수 있음
* macOS에서 종료할 때 임의로 충돌할 수 있음
