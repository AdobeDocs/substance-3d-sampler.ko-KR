# 0.5.3

출시일: **2019/03/19**

추가됨:

* 리소스 패널에서 재질 이름으로 검색
* [UI] 브러시 크기 시각화를 사용한 복제 도구의 새 UI
* [UI] 숨겨진 스테이지 선택 및 삭제
* [UI] 새 텍스트 필드 UI
* [도움말] Substance Source, Substance share 및 Substance 아카데미 웹 사이트에 액세스
* [콘텐츠] 생성기 및 아틀라스가 있는 새로운 기본 재질
* [Content] 비트맵에서 재질로 업데이트
* [Content] Dirt 업데이트
* [Content] 녹 업데이트
* [내용] 새로운 엠보싱 필터
* [콘텐츠] 새로운 자수 필터
* [Content] 새 침식 필터
* [콘텐츠] 새로운 자갈 생성기
* [내용] 새로운 페인트 필터
* [내용] 새로운 쪽매 패턴 필터
* [Content] 새로운 포장 패턴 필터
* [내용] 새로운 천공 필터
* [콘텐츠] 새로운 스플래터 필터
* [Content] 새로운 섬유 마모 필터
* [Content] 새로운 변형 필터

수정:

* [뷰포트] X에 x2 타일링이 있는 구 메시
* [뷰포트] 나만의 환경을 로드할 때 충돌이 발생함
* [뷰포트] 환경 맵에서도 이제 노출 값을 사용하고 있습니다.
* [뷰포트] F 단축키가 카메라 각도를 재설정하지 않음
* [내보내기] SBS 내보내기가 최신 Substance Designer 2018.3.3에서 작동합니다.
* [내보내기] SBSAR 내보내기는 Substance Source 재질과 동일한 지침을 준수합니다
* [UI] 스크롤 막대를 드래그할 수 있습니다.
* 폴더 및 파일 경로에서는 특수 문자가 지원됩니다
* 자료를 저장할 때 썸네일이 다시 생성됩니다.

알려진 문제:

* 하나의 재질에 여러 개의 흐림 효과를 사용하는 것은 권장되지 않습니다
* 구형 NVIDIA 드라이버에서 Delighter 충돌(400.x 미만)
* Delighter 단계의 빠른 가시성 전환은 성능에 영향을 줍니다.
* 사용자 정의 환경 가져오기가 검은색으로 바뀔 수 있음
* 이미지 가져오기 레이어의 [속성] 패널에 TIF 이미지가 표시되지 않습니다
* 슬라이더에서 특정 값을 입력할 때 혼수 또는 점을 무시할 수 있습니다
* 저장할 기본 컬렉션은 비워 둘 수 있습니다.
