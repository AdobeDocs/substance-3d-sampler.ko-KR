# 버전 3.4

**Substance 3D Sampler 3.4.0**&#x200B;에서는 3D 작업 과정의 속도와 품질을 높이기 위해 설계된 일련의 새로운 기능을 소개합니다.

*출시일: 2022년 9월 6일*

## 주요 기능

## 노출된 파라미터

CLO, UE5, Blender, Photoshop, Illustrator 등 SBSAR 파일을 지원하는 소프트웨어 내에서 파라메트릭 재질을 수정합니다.\
이제 이러한 작업이 가능한 이유는 Sampler의 새로운 에셋 매개 변수 노출 기능을 통해 반복 속도를 높이고 Sampler과 다른 소프트웨어 간의 오락과 소동을 없앨 수 있기 때문입니다.

핀을 클릭하여 재료의 매개변수를 표시합니다.

색상 점을 사용하면 노출된 매개 변수와 다양한 패널로 이동할 수 있습니다.

## Python 작성

이제 플러그인과 스크립트를 만들 수 있습니다. 이렇게 하면 인터페이스를 사용자 정의하여 Sampler을 파이프라인에 쉽게 통합하고 원하는 방식으로 작업 과정을 전반적으로 설정할 수 있습니다.\
예를 들어 이 기능을 사용하면 한 번의 클릭으로 여러 재질을 내보낼 때 반복 작업을 자동화할 수 있는 스크립트를 만들 수 있습니다.

첫 번째 플러그인 또는 스크립트를 만드는 방법을 알아봅니다. [여기](../scripting-and-development/scripting-and-development.md).

## CLO 물리적 속성

이제 물리적 시뮬레이션을 사용하여 사실적으로 작동하는 텍스타일을 만들 수 있습니다. 이는 직물의 Bending, Shear, Friction 등의 물성을 입력함으로써 이루어진다.\
이번 업데이트를 통해 SBSAR는 CLO에서 재료가 사실적으로 반응하도록 사용하는 메타데이터에 물리학 정보를 포함합니다.

## Image to Material(AI 기반)

이제 Image to Material(AI 작동)을 MacOS에서 사용할 수 있으며 Apple Silicon 장치에서 기본적으로 실행됩니다.
