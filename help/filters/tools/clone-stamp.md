## 설명

**복제 도장 도구**&#x200B;를 사용하면 재질의 일부를 수동으로 복제하거나 패치할 수 있습니다. 이음새를 수정하거나 재질에서 오류를 제거하는 데 유용합니다. **복제 도장 필터**&#x200B;는 왼쪽 사이드바에서 사용할 수 있는 도구 중 하나입니다.

아래 이미지는 눈 재질에 있는 이물질을 제거하는 데 사용되는 **복제 도장**&#x200B;을 보여줍니다.

![](../../assets/3d-2d-filters-cropped-0049-clone-stamp-in.jpg)

상기 이미지에서, 눈 재료는 다수의 잔가지들과 주위에 흩어진 다른 잔해들을 포함한다.

![](../../assets/3d-2d-filters-cropped-0048-clone-stamp-out.jpg)

**복제 도장** 도구는 일부 잔가지를 제거하고 깨끗한 눈으로 바꾸는 데 사용됩니다.

## 복제 도장 튜토리얼

## 매개변수

<b>기본 매개 변수</b>

* <b>마스크 확장</b>: 0-1\
  필터가 기본 재질과 일치시키려고 시도하는 페인트 영역 주위의 거리를 조정합니다.
* <b>혼합 페이드</b>: 0-1\
  복제된 영역의 가장자리를 부드럽게 하여 기본 재질과 더욱 잘 혼합되도록 합니다.
* <b>흐림 효과 마스크</b>: 0-1\
  복제 도장 가장자리의 세부 정도를 조정합니다. 이 값을 늘리면 복제된 영역의 가장자리가 물방울 모양과 비슷해집니다.
* <b>비율 유지</b>: 전환\
  끄면 스탬프 영역의 비율을 조정할 수 있습니다.
  * <b>가로</b>: 0-2
  * <b>수직</b>: 0-2
* <b>회전</b>: -180 - 180\
  스탬프 영역을 회전합니다.
* <b>가로로 뒤집기</b>: 전환\
  스탬프 영역을 가로축을 따라 대칭복사합니다.
* <b>세로로 뒤집기</b>: 전환\
  스탬프 영역을 세로 축을 따라 대칭복사합니다.

<b>혼합 페이드</b>

[희미하게 하기 혼합] 컨트롤을 사용하여 재질의 각 채널에 대해 희미하게 하기 혼합을 개별적으로 조정할 수 있습니다.

<b>고급</b>

* <b>표준 강도</b>: 0-2\
  스탬프 영역의 표준 강도를 조정합니다.
* <b>원본 위치</b>: \
  0-1: 가로 소스 위치를 조정합니다.\
  0-1: 세로 소스 위치를 조정합니다.
* <b>대상 위치</b>:\
  0-1: 수평 대상 위치를 조정합니다.\
  0-1: 세로 대상 위치를 조정합니다.
* <b>타일링 모드</b>: 드롭다운\
  타일링을 활성화 또는 비활성화합니다.

## 사용 안내서

**복제 도장 도구**&#x200B;를 클릭하여 레이어 스택 맨 위에 새 복제 도장 필터 레이어를 만듭니다. **레이어 패널**&#x200B;에서 **레이어 추가 단추**&#x200B;를 사용하여 복제 도장 필터를 추가할 수도 있습니다.

복제 도장 필터 레이어를 만들면 **뷰포트**&#x200B;에서 **2D 보기**&#x200B;가 자동으로 열립니다. 복제 도장 레이어를 선택하면 **2D 보기**&#x200B;의 위쪽에 **도구 모음**&#x200B;이 나타납니다.

![](../../assets/alchemist-2020-2-clone.gif){width="300px"}

복제 도장 도구를 사용하려면 **2D 보기**&#x200B;에서 문제가 있는 영역을 클릭하고 드래그합니다. 재질은 출처를 기준으로 자동 업데이트를 시작합니다. **복제 도장 도구**&#x200B;를 사용하는 영역이 강조 표시됩니다.

## 소스 선택

새 소스를 추가하려면 2D 뷰에서 Ctrl 키를 누른 채 클릭 을 사용합니다. 새 소스를 추가하면 <b>레이어 패널</b>의 복제 도장 레이어 아래에 추가 도장이 만들어집니다. 각 스탬프를 개별적으로 제어할 수 있습니다.

>[!NOTE]
>
> 일반적으로 복제 중인 영역 가까이에 소스 포인트를 두지 않는 것이 좋습니다. 소스 지점이 문제 영역과 가까운 경우 문제 영역을 복제할 수 있습니다.
