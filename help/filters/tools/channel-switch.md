## 매개변수

**기본 매개 변수**

* **맞춤 직조 그리기:** 2D 뷰포트에서 직조를 그립니다.
* **입력 채널:** 필터가 이동할 채널을 선택합니다.
* **출력 채널:** 입력 채널의 대상이 되는 채널을 선택합니다.
* **불투명도:** 0-1\
  기존 채널 정보를 기준으로 채널 정보의 불투명도를 조정합니다. 즉, 새 채널 칠을 적용하는 데 사용되는 마스크의 불투명도를 제어합니다.
* **혼합 모드****:** 기본 색상 채널의 혼합 모드를 선택합니다. 혼합 모드를 변경하면 채널의 모양이 거의 변경될 수 있습니다.

**고급**

* **재질 입력:** 입력으로 사용할 재질을 선택합니다.

**마스크**

* **사용자 지정 마스크 사용:** 토글\
  사용자 정의 마스크 사용을 활성화하거나 비활성화합니다. 활성화하면 다음 매개변수가 나타납니다.
* **사용자 지정 마스크 - 흐림 효과:** 0-1\
  마스크를 흐리게 합니다.
* **사용자 지정 마스크 - 반전:** 전환\
  마스크를 반전합니다.
