## 설명

이미지의 원근감 문제를 해결하려면 <b>원근감 도구 </b>을(를) 사용하십시오. <b>원근감 변환</b>도 재질에 사용할 수 있습니다.

아래 이미지는 <b>원근감이 변환 도구</b>를 수정하기 전의 예시 자료입니다. 2D 보기의 윗부분 모양은 2D 보기 아래쪽의 모양에 비해 세로로 얼마나 큰지 살펴보세요.

![](../../assets/3d-2d-filters-cropped-0005-perspective-in.jpg)

<b>원근감</b>을 사용하면 모양이 일관되고 그리드를 형성합니다. <b>타일링</b> 또는 <b>타일링하게 만들기</b>와 같은 필터를 사용하여 이를 타일링 가능한 재질로 변환하는 것은 이 시점부터 쉬울 것입니다.

![](../../assets/3d-2d-filters-cropped-0004-perspective-out.jpg)

## 사용 안내서

원근감 변환 레이어가 선택된 상태에서 2D 보기의 각 모서리에 핸들이 나타납니다. 2D 공간에서 개별적으로 이동하여 원근감을 수정합니다.

![](../../assets/alchemist-2020-2-perspective.gif){width="300px"}

## 도구 모음

원근감 변환 레이어가 선택된 상태에서 도구 모음이 **2D 보기**&#x200B;의 위쪽에 나타납니다. **위치 재설정 버튼{Reset positions}을 사용하여 원근감 0 변환 1 레이어의 핸들을 기본 위치로 재설정합니다.**
