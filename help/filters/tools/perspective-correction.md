## 설명

<b>원근감 변형 도구 </b>를 사용하여 이미지의 원근 문제를 수정하세요. <b>원근 변환</b>은(는) 재질에도 사용할 수 있습니다.

아래 이미지는 <b>원근감 변형 도구</b>로 수정되기 전의 예제 재질을 보여 줍니다. 2D 보기 위쪽에 있는 모양이 2D 보기 아래쪽에 있는 모양과 비교하여 세로로 늘어나 있는지 확인합니다.

![](../../assets/3d-2d-filters-cropped-0005-perspective-in.jpg)

<b>원근 변형</b>을 사용하면 모양이 일관되고 격자를 형성합니다. <b>타일링</b> 또는 <b>타일링하게 만들기</b>와 같은 필터를 사용하여 이를 타일링 가능한 재질로 변환하는 것은 이 시점부터 쉬울 것입니다.

![](../../assets/3d-2d-filters-cropped-0004-perspective-out.jpg)

## 사용 안내서

[원근감 변형] 레이어를 선택하면 2D 보기에서 텍스처의 각 모퉁이에 핸들이 나타납니다. 2D 공간에서 개별적으로 이동하여 원근을 교정합니다.

![](../../assets/alchemist-2020-2-perspective.gif){width="300px"}

## 도구 모음

[원근감 변형] 레이어를 선택하면 **2D 보기** 위쪽에 도구 모음이 나타납니다. **위치 재설정 버튼**&#x200B;을 사용하여 원근감 변형 레이어의 핸들을 기본 위치로 재설정합니다.
