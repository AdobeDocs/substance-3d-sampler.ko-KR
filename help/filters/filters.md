# 필터

>[!IMPORTANT]
>
> Sampler V5.2의 릴리스에서는 환경 조명 및 메시에 대한 지원이 제거됩니다. 환경 조명의 제거에는 HDRI 도구 및 필터 제거도 포함됩니다.

Adobe Substance 3D Sampler 필터는 에셋을 수정하고 조정하는 데 사용되는 기본 도구입니다. Sampler에는 다음과 같은 유형의 필터가 포함됩니다.

* [생성기](../filters/generators/generators.md) - 재질에 새 요소를 도입합니다.
* [조정](../filters/adjustments/adjustments.md) - 재질의 채널 값을 조정합니다.
* [도구](../filters/tools/tools.md) - 기술적 문제를 찾아 해결합니다.
* [HDRI 도구](../filters/hdri-tools/hdri-tools.md) - 환경 조명에 특정한 필터입니다.
* [마르고 마무리하기](../filters/wear-and-finish/wear-and-finish.md) - 재질의 모양과 느낌을 변경합니다.

Adobe Substance 3D Designer을 사용하여 나만의 필터를 만들 수 있습니다. [방법](custom-filters.md)을 찾으려면 여기로 이동하세요.

필터는 다양한 기술을 기반으로 할 수 있습니다.

* Substance Designer으로 만든 절차 필터
* C++ 및/또는 인공 지능을 사용하여 직접 만든 이미지 처리 필터

대부분의 필터는 재질 또는 이미지에 사용할 수 있습니다. 일부 필터에는 채널 설정 측면에서 특정 요구 사항이 있습니다. 필터가 예상대로 작동하지 않으면 설명서에서 해당 필터를 검색하여 사용 안내서를 참조하십시오.
