## 매개변수

**기본 매개 변수**

* **임의화**:\
  이 필터의 다른 모든 임의 매개 변수가 기반으로 하는 임의 초기값입니다.
* **돌 패턴**:\
  돌을 정렬하는 데 사용할 패턴 선택
* **돌 양**: 4-18\
  재질을 분할할 돌의 수를 조정합니다
* **돌 원형**: 0-1\
  돌 가장자리의 마모 제어
* **결석 평탄 양**: 0-1\
  돌 사이의 모르타르에 대한 돌의 상대 Height 조정
* **모르타르 Thickness**: 0-1\
  돌 사이의 간격 조정
* **모르타르 Height**: 0-1\
  돌 사이 모르타르의 Height 증가 또는 감소
* **모르타르 색상**: 색상 선택\
  돌 사이 모르타르의 색상 조정
* **그림 양**: 0-1\
  재료에 적용된 그림 및 Dirt 양 변경
* **그림 색상**: 색상 선택\
  그림자의 색상 선택

**고급 매개 변수**

* **표준 강도**: 0-3\
  전체 재질에 대한 표준의 강도를 제어합니다.
