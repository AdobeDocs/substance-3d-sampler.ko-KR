## 매개변수

**기본 매개 변수**

* **임의화**:\
  임의식은 이 필터에서 임의성을 사용하는 다른 매개 변수의 임의값을 결정합니다.
* **재료 입력**:\
  입력으로 사용할 재질 수를 선택합니다. 참고: 입력 슬롯이 3개 있지만 입력 슬롯이 1개만 있는 스플래터 레이어는 입력 슬롯이 1개인 스플래터 레이어와 동일한 입력 슬롯이 있는 스플래터 레이어와 다르게 표시됩니다. 따라서 필요한 만큼 입력만 사용하는 것이 좋습니다.
* **격자 크기**: 1-64\
  격자 크기는 스플래터 필터로 생성되는 인스턴스 수를 결정합니다.
* **AO Height 깊이**: 0-1\
  필터로 만든 인스턴스의 AO 강도를 조정합니다.

**모양**

* **비율**: 0-5\
  모든 인스턴스의 기본 크기 조정
* **무작위 크기 조정**: 0-1\
  각 인스턴스에 대한 비율 값의 임의성 조정
* **겹치지 않게 크기 조정**: 0-1\
  오버랩 방지를 위해 인스턴스 크기 수정
* **위치 무작위**: 0-2\
  인스턴스 분산의 임의성 제어
* **회전 무작위**: 0-1\
  인스턴스 회전의 임의성 제어
* **배경 경사에서 회전**: 0-1\
  기본 재질의 표준이 인스턴스 회전에 미치는 영향의 정도를 수정합니다.

**기본 색상**

* **알베도 일치**: 0-1\
  인스턴스 색상을 기본 재질의 색상과 일치
* **HSL 조정**: 0-1\
  인스턴스의 색조, 채도 및 밝기 조정
* **HSL 무작위**: 0-1\
  각 인스턴스의 색조, 채도 및 명도의 임의성 제어

**표준**

* **표준** **배경**: 0-1\
  각 인스턴스에서 재질의 법선이 인스턴스의 법선에 영향을 미치는 정도를 조정합니다.
* **표준 각도 무작위**: 0-1\
  각 인스턴스의 법선을 임의의 각도로 기울입니다.

**거칠음**

* **거칠기 조정**: -1 - 1\
  예제에 걸쳐 거칠기 값을 균일하게 추가 또는 빼기
* **거칠음 무작위**: -1 - 1\
  각 인스턴스의 거칠기 값에서 무작위로 더하거나 빼기
* **배경에서 거칠음**: 0-1\
  기본 재질의 거칠기 값이 각 인스턴스의 거칠기 값에 미치는 영향을 조정합니다

**Height**

* **Height 오프셋**: -1 - 1\
  인스턴스 Height을 오프셋합니다. 인스턴스가 기본 재질과 혼합되는 방식에 영향을 줄 수 있습니다.
* **Height 오프셋 무작위**: 0-1\
  각 인스턴스의 Height 오프셋에 임의의 값 추가
* **Height 크기**: 0-2\
  모든 인스턴스의 Height을 조정합니다.
* **Height 비율 무작위**: 0-1\
  각 인스턴스의 Height에 임의의 값 추가
* **배경 경사에서 기울이기**: 0-1\
  기본 재질의 경사와 일치하도록 각 인스턴스에 경사를 추가합니다
* **배경 경사 Smoothness**: 0-2\
  **배경 경사에서 기울이기** 매개 변수를 사용하기 위해 배경의 경사를 조정합니다.
* **배경 일치**: 0-1\
  백그라운드 Height 맵이 인스턴스 Height 맵에 미치는 영향을 제어합니다. 이렇게 하면 배경 세부 사항 주위의 인스턴스를 축소-줄 바꿈할 수 있습니다
* **일치된 배경 매끄럽게**: 0-1\
  **배경 일치**(으)로 인해 표시되는 세부 사항의 양을 조정합니다.

**금속**

* **금속 조정**: -1 - 1\
  인스턴스의 금속성 값 제어
* **금속 무작위**: -1 - 1\
  각 인스턴스의 금속에서 임의의 값 추가 또는 빼기
* **배경의 금속**: 0-1\
  배경의 금속 값이 각 인스턴스에 미치는 영향을 조정합니다

**마스크**

* **사용자 지정 마스크 사용**: 전환\
  사용자 정의 마스크를 사용하고 사용자 정의 마스크 컨트롤에 액세스하려면 이 옵션을 활성화합니다.
  * **사용자 지정 마스크**: 이미지/브러시\
    사용자 지정 마스크로 사용하거나 **2D 보기**&#x200B;에서 직접 칠할 이미지 가져오기
  * **사용자 지정 마스크 흐림 효과**: 0-1\
    사용자 정의 마스크의 가장자리 흐리게 하기
  * **사용자 지정 마스크 반전**: 전환
  * **사용자 지정 마스크 불투명도**: 0-1\
    사용자 정의 마스크의 강도 조정

사용 안내서

튄 필터 를 사용하면 나뭇잎, 돌 또는 휴지통과 같은 재질 에셋을 산란 할 수 있습니다.

스플래터 필터 사용 방법:

1. 레이어 스택에 스플래터 필터 추가
1. 스플래터 레이어 아래에 입력 슬롯이 나타납니다
1. 선택적으로 **기본 매개 변수 > 재료 입력**&#x200B;으로 사용할 수 있는 입력 슬롯 수를 변경합니다.
1. 재료를 스플래터 입력 슬롯으로 드래그합니다.

[스플래터] 레이어를 선택하여 **산란 패널**&#x200B;에서 속성 매개 변수를 조정할 수 있습니다.

입력 슬롯에서 재질을 선택하여 **속성 패널**&#x200B;에서 입력 재질의 매개 변수를 조정할 수 있습니다.
