## 설명

바닥 타일 필터는 기본 재질을 분할하고 바닥 타일의 배열로 변환합니다.

매개변수

<b>기본 매개 변수</b>

* <b>임의화</b>: \
  임의식은 이 필터에서 임의성을 사용하는 다른 매개 변수의 임의값을 결정합니다.
* <b>재질 수</b>: \
  바닥 타일로 변환할 재료의 수를 변경합니다. 첫 번째 재질은 Floor Tiles 필터 레이어 아래의 레이어에 의해 결정됩니다. 이 옵션을 선택하면 두 번째 값을 입력으로 추가할 수 있습니다.
* <b>입력 재질 강도</b>: 0-1 \
  타일에 입력 자료의 세부 정보가 얼마나 표시됩니까?
* <b>재질 반전</b>: 전환 \
  두 재질을 사용하는 경우 타일에서 해당 재질이 나타나는 위치를 교환합니다.
* <b>색상 변형</b>: 0-1 \
  동일한 재질의 각 타일 간 색상 변화 정도
* <b>경사 반경</b>: 0-1 \
  타일의 크기와 모르터의 크기 비교
* <b>경사 깊이</b>: 0-1 \
  박격포 깊이
* <b>경사 원형률</b>: 0-1 \
  타일의 외부 각도를 정합니다
* <b>표면 그레인</b>: 0-1 \
  타일의 표준 및 Height 맵에 원본 재질의 디테일이 표시되는 정도를 결정합니다
* <b>패턴 마스크</b>: 입력했습니다.  \
  각 바닥 타일 패턴 마스크에는 사용 가능한 다른 매개 변수 세트가 있습니다. 여기서는 <b>정사각형 타일</b>에 사용할 수 있는 매개 변수만 다룹니다

  * <b>임의 시드 </b>\
    임의식은 이 필터에서 임의성을 사용하는 다른 매개 변수의 임의값을 결정합니다.
  * <b>X 양 </b>\
    타일 열 수 조정
  * <b>Y 양</b> \
    타일 줄 수 조정
  * <b>그레이디언트 </b> \
    절구체 크기에 비해 타일 크기의 비율을 조정합니다.
  * <b>광도 무작위</b>\
    광도가 Height 맵에 영향을 주므로 이 매개 변수는 임의로 일부 타일을 제거합니다
  * <b>패턴 회전</b>: 0-1 \
    타일의 각도를 회전하여 겹침 방지를 위해 타일이 서로 겹치지 않게 합니다
  * <b>모양 비율:</b> 0-1 \
    절구체 크기에 비해 타일 크기의 비율을 조정합니다.
  * <b>모양 비율 무작위 </b>\
    타일 크기에 약간의 차이를 임의로 추가합니다
  * <b>모양 크기 </b>\
    타일의 길이와 폭 조정
  * <b>모양 크기 무작위 </b>\
    타일의 길이와 폭에 약간의 임의성 추가
  * <b>위치 오프셋 모드</b>: 드롭다운 목록
  * <b>위치 오프셋 </b>\
    타일이 가로로 정렬되지 않도록 타일 열을 임의로 이동합니다
  * <b>위치 무작위</b> \
    타일 사이에 약간의 잠재적 중첩과 함께 타일을 표면에 배열합니다
  * <b>모양 회전 </b>\
    타일의 각도를 같은 방향으로 회전하면서 가능한 한 겹쳐 놓아 가깝게 유지합니다
  * <b>모양 회전 무작위 </b>\
    타일의 각도를 가능한 한 가깝게 유지하면서 가능한 한 회전할 수 있도록 회전

<b>간격</b>

* <b>간격 색상</b>: 색상 선택 \
  타일 간 색상 변경
* <b>간격 거칠음</b>: 0-1 \
  타일 간 재질의 거칠기 값을 변경합니다.
* <b>간격 금속</b>: 0-1 \
  타일 간 재질의 금속성 값을 변경합니다.
* <b>간격 Height</b>: 0-1 \
  타일 간 재질에 대한 Height 값을 변경합니다.
* <b>간격 불규칙성</b>: 0-1 \
  모르타르가 타일 사이에 얼마나 깔끔하게 적용될지 조정하세요.

<b>나이</b>

* <b>바닥 기울기</b>: 0-1 \
  무작위 타일에 약간의 틸트 추가
* <b>무작위 Height</b> \
  타일 간 Height 차이를 무작위로 추가
* <b>Dirt</b>: 0-1 \
  타일 및 간격에 Dirt 추가
* <b>손상</b>: 0-1 \
  각 타일의 경사 가장자리에서 임의로 일부 샤드를 제거합니다
* <b>결함</b> \
  타일에 작은 구멍 및 결함 추가

<b>기술 매개 변수</b>

* <b>재질 크기</b>: 0-1 \
  타일 내 재료의 배율
* <b>표준 강도</b>: 0-1 \
  간격, 타일 및 내부 재질의 수직 강도를 조정합니다

<b>사용 안내서</b>

바닥 타일 필터를 사용하면 재질을 타일로 빠르게 변환할 수 있습니다. 바닥 타일 필터는 여러 재료를 사용할 때를 제외하고는 대부분 사용하기에 매우 간단합니다. 두 재질을 사용하려면 다음을 수행합니다.

1. <b>기본 매개 변수 > 재질 수</b>를 2로 설정합니다.
1. 두 번째 재질을 레이어 스택의 Floor Tiles 필터 아래에 표시된 입력 슬롯으로 드래그합니다.
1. 결과가 만족스러울 때까지 입력 자료의 매개 변수를 조정합니다.

하나의 입력 슬롯에 여러 재질과 필터를 추가할 수 있지만 일반적으로 복잡한 부분이 추가되어 나중에 다시 사용할 때 재질을 읽기 어렵게 만들 수 있으므로 이렇게 하지 않는 것이 좋습니다. 그 대신 프로젝트에서 새 재질을 만든 다음 새 재질의 인스턴스를 입력 슬롯으로 드래그합니다. 프로젝트의 재질을 업데이트하면 입력 슬롯의 재질이 자동으로 업데이트되어 완전한 제어 기능을 제공하고 레이어 스택을 단순화할 수 있습니다.
