# Generators

제네레이터는 재질을 추가로 변경하는 필터입니다. 발전기는 종종 재료의 외관에 상당한 변화를 초래하고 그 결과로 재료의 기초를 만드는 데 정기적으로 사용됩니다.

발전기의 주된 형태는 두 가지입니다.

* 변환 생성기는 **패널 필터**&#x200B;를 사용하여 평면 스틸 재질을 여러 패널로 변환하는 것과 같이 기본 재질을 새로운 형태로 변환합니다.
* 생성기를 추가하면 기본 재질 위에 입력 아틀라스의 재질 전체에서 개체를 산란 하는 **Atlas Scatter 필터**&#x200B;와 같은 새 요소가 추가됩니다.

변환 생성기는 다음과 같습니다.

* [벽돌](brickwall.md)
* [바닥 타일](floor-tiles.md)
* [패널](panel.md)

* [인도](pavement.md)
* [퀼트 스티치](quilt-stitch.md)
