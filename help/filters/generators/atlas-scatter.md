## 설명

Atlas Scatter 필터는 기본 재질에 걸쳐 아틀라스 재질 내에 있는 요소의 인스턴스를 산란 합니다. Atlas Scatter은 나뭇잎, 바위 또는 쓰레기와 같은 것들을 재료 전체에 자연적인 방식으로 흩뿌리는 데 유용합니다.

아래 이미지는 **Atlas Scatter 필터**&#x200B;를 작동 상태로 표시합니다.

![](../../assets/3d-2d-filters-cropped-0037-atlas-scatter-in.jpg)

**Atlas Scatter 필터**&#x200B;를 사용하기 전에 기본 진흙 재질이 있습니다. 흥미진진하지는 않습니다.

![](../../assets/3d-2d-filters-cropped-0036-atlas-scatter-out.jpg)

조약돌 지도와 함께 **Atlas Scatter 필터**&#x200B;를 추가하면 조약돌이 흩어지고 밑에 있는 진흙과 사실적으로 혼합되므로 재질이 더 흥미로워집니다.

## 매개변수

**기본 매개 변수**

* **X 양**: 1-64\
  X축의 인스턴스 수
* **Y 양**: 1-64\
  Y축의 인스턴스 수
* **혼합 모드**:\
  기본 레이어와 혼합하는 데 사용되는 방법
* **비율**: 0-5\
  인스턴스 비율 조정
* **위치 무작위**: 0-2\
  격자 위치에서 인스턴스의 임의 오프셋 증가 또는 감소
* **Height 크기**: 0-1\
  인스턴스 Height 조정
* **배경 일치**: 0-1\
  기본 Height 값이 분산된 인스턴스에 미치는 영향 변경
* **배경색**:
  * **색조:** 0-1\
    인스턴스의 색조 조정
  * **채도:** 0-1\
    인스턴스의 채도 조정
  * **값:** 0-1\
    인스턴스 값 조정

**마스크**

* **사용자 지정 마스크**: 토글\
  사용자 정의 마스크 사용을 활성화하거나 비활성화합니다. 활성화하면 다음 컨트롤이 나타납니다.
  * **사용자 지정 마스크:**\
    마스크로 사용할 파일을 선택하거나 브러시 모드를 사용하여 수동으로 마스크를 만듭니다.
  * **마스크 반전:** 전환\
    마스크 값 반전
* **무작위 마스크**: 0-1\
  무작위로 인스턴스 비율 숨기기

**크기**

* **무작위 크기 조정**: 0-1\
  각 인스턴스에 적용할 임의화된 비율의 양입니다
* **겹치지 않게 크기 조정**: 0-1\
  인스턴스가 겹치지 않도록 각 인스턴스의 크기를 조정합니다

**Height**

* **Height 오프셋**: -1 - 1\
  기본 레벨 0에서 인스턴스 Height 오프셋
* **Height 오프셋 무작위**: 0-1\
  각 인스턴스의 Height 오프셋에 임의의 값 추가
* **배경 경사에서 기울이기**: 0-1\
  배경 경사를 기반으로 표준의 기울이기 조정
* **배경 Smoothness**: 0-2\
  배경 조정 Smoothness

**회전**

* **회전**: 0-1\
  모든 인스턴스를 설정된 값으로 회전
* **회전 무작위**: 0-1\
  각 인스턴스의 회전에 임의의 값 추가
* **배경 경사에서 회전**:\
  기본 재질의 경사를 기준으로 인스턴스 회전

**아틀라스 재질 조정**

* **색상 조정**:\
  지도에 대한 HSV 값 조정
* **색상 무작위**:\
  **색상 조정**&#x200B;에 설정된 HSV 값에 임의성을 추가합니다.
* **배경에서 거칠음**: 0-1\
  각 인스턴스의 거칠기 대신 배경의 거칠기를 사용합니다.
* **거칠기 조정**: -1 - 1\
  각 인스턴스에서 거칠기 값을 추가하거나 뺍니다.
* **보통 무작위**: 0-1\
  각 인스턴스의 표준을 인스턴스당 임의의 값으로 회전
* **앰비언트 오클루전 다시 계산**: 전환\
  이 옵션을 켜면 수정된 오클루전 값을 기반으로 앰비언트 Height 값이 다시 계산됩니다

**아틀라스 모양 감지**

* **패턴 범위**:\
  위치에 따라 지도에서 사용 가능한 에셋을 제한합니다. X 및 Y 값을 0으로 두고 아틀라스의 모든 에셋을 사용합니다.
* **아틀라스 불투명도 축소**: 0-4
* **모양 검색 정밀도**:\
  모양을 감지할 알고리즘을 선택합니다. 상이한 아틀라스가 상이한 검출 알고리즘에 적합할 것이다. No failure 모드는 다른 옵션보다 계산 비용이 더 높습니다.
* **다음보다 작은 모양 무시**: 0-1\
  이 옵션을 사용하면 매우 작은 모양을 개별 요소로 선택하지 않을 수 있습니다.

사용 안내서

Atlas Scatter 필터는 나뭇잎, 돌 또는 휴지통과 같은 재질 전반에 걸쳐 에셋을 산란 하는 데 유용합니다. Atlas Scatter 필터를 사용하려면 필터가 처리될 수 있도록 아틀라스 재질이 필요합니다.

>[!NOTE]
>
> 아틀라스 재질은 별도의 자산에 대한 모음(또는 아틀라스)을 보유하는 자료입니다. 예를 들어 Sampler에는 기본적으로 월계수 잎이 포함되어 있습니다. 월계수 잎은 각각의 잎이 서로 분리되어 있는 단일 재질에 잎 모음을 포함하고 있으므로 아틀라스 재질입니다. Atlas Scatter 노드는 알고리즘을 이용하여 아틀라스 물질의 각 잎을 별도의 요소로 취급한다.

Atlas Scatter 필터를 사용하려면 다음을 수행하십시오.

1. 레이어 스택에 Atlas Scatter 필터 추가
1. Atlas Scatter 레이어 아래에 입력 슬롯이 나타납니다
1. 아틀라스 재질을 Atlas Scatter 입력 슬롯으로 드래그합니다

Atlas Scatter 레이어를 선택하여 **산란 패널**&#x200B;에서 속성 매개 변수를 조정할 수 있습니다.

입력 슬롯에서 재질을 선택하여 **속성 패널**&#x200B;에서 아틀라스 재질의 매개 변수를 조정할 수 있습니다.
