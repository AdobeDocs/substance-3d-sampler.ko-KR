## 매개변수

**사전 설정**

여러 사전 설정 중에서 선택하여 특정 스타일을 빠르게 에뮬레이션합니다.

**기본 매개 변수**

* **임의 시드**: 임의 숫자\
  이 필터에서 다른 임의의 값을 결정하는 데 사용되는 임의의 값입니다.\
  새로운 난수 값을 얻으려면 숫자를 클릭합니다. 임의의 값을 선택한 경우 매개 변수 이름을 클릭하여 값을 0으로 재설정합니다.
* **벽돌 쌓기**:\
  선택한 스타일에 따라 벽돌을 병합합니다
* **벽돌 유형**:\
  벽돌 스타일 선택
* **타일**: 1-25\
  X축과 Y축의 타일링 양을 변경합니다.
* **오프셋**: 0-1\
  앞의 행에서 각 벽돌 행의 오프셋을 수정합니다.
* **사용자 지정 색 사용**: 전환\
  선택한 스타일에 따라 벽돌을 병합합니다

**믹스**

* **혼합 모드**:\
  벽돌 구성 방식을 변경합니다. **혼합 모드**&#x200B;를 사용하면 기본 세트와 독립적으로 제어할 수 있는 두 번째 벽돌 세트가 만들어집니다.\
  **혼합 모드**&#x200B;를 **없음**(으)로 설정하면 이 섹션에 다른 매개 변수가 표시되지 않습니다.
* **벽돌 유형 2**:\
  두 번째 벽돌 세트의 스타일을 선택합니다.
* **Height 오프셋**: 0-1\
  두 번째 벽돌 세트의 Height 오프셋

**시멘트**

* **시멘트 색상**: 색상 피커\
  벽돌 사이의 시멘트 색상을 변경합니다.
* **시멘트 거칠음**: 0-1\
  벽돌 사이의 시멘트 거칠기를 변경합니다.
* **시멘트 공극**: 0-1\
  벽돌 사이의 시멘트 폭을 변경합니다. 벽돌 크기를 변경합니다.
* **시멘트 레벨**: 0-1\
  시멘트 Height 변경
* **시멘트 장애**: 0-1\
  시멘트의 평탄도를 조정합니다. 높은 가치에서는 시멘트가 벽돌 위로 올라갈 수 있다.

**나이**

* **벽돌 장애**: 0-1\
  각 벽돌의 회전을 3차원에서 무작위로 조정합니다.
* **벽돌 산산조각**: 0-1\
  벽돌로 균열 추가
* **벽돌 가장자리**: 0-1\
  벽돌의 가장자리 손상 및 깨짐
* **벽돌 분리**: 0-1\
  무작위로 벽돌 제거
* **벽돌 색상 변형**: 0-1\
  벽돌의 색상을 다양하게 조정하여 벽이 덜 균일하게 보이도록 합니다
* **벽돌 더러움**: 0-1\
  벽돌에 Dirt 추가

**고급 매개 변수**

* **Height 혼합 강도**: 0-1\
  기본 재질에서 Height의 혼합을 조정합니다. 값을 0으로 지정하면 기본 재질의 Height은 무시되고 브릭월 필터 매개 변수만 사용하여 Height 정보를 생성할 수 있습니다. 값을 1로 지정하면 기본 재질이 Height 정보를 생성합니다.
* **표준 강도**: 0-1\
  임계값 필터로 생성된 표준의 강도를 조정합니다. 0이라는 값은 사실상 정규식이 없음을 의미합니다.
* **주변 오클루전 강도**: 0-1\
  AO의 강도를 조정합니다. 값을 0으로 지정하면 사실상 앰비언트 오클루전이 없음을 의미합니다.

사용 안내서

[벽돌] 필터는 기본 재질을 개별 벽돌로 분할한 다음 다시 정렬합니다. 따라서 브릭월 필터는 암석이나 금속과 같은 단단한 표면에 가장 적합합니다. 즉, 실제 벽돌에 가장 적합한 재질입니다.

[임계값] 필터는 기본 재질을 만들 때 유용합니다. 이 필터를 사용하면 이끼, 눈, Dirt 등의 다른 효과도 레이어링할 수 있습니다.
