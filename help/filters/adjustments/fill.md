## 설명

**채우기 필터**를 사용하면 선택한 값에 따라 특정 채널의 값을 바꾸거나 조정할 수 있습니다.
Sampler 6.0에서 칠 필터는 적용되는 채널 유형에 따라 매개 변수를 조정합니다. 이렇게 하면 사용 가능한 컨트롤이 항상 선택한 채널의 실제 의미 및 데이터 형식과 일치하고 사용자 지정 워크플로우에서도 모든 맵에 필터를 적용할 수 있습니다.

## 매개변수

<b>적용 대상...</b>

적용 대상... 드롭다운은 채우기 필터가 영향을 미치는 채널을 결정합니다.
**현재 재질의 채널 설정에서 사용할 수 있는 채널만 이 목록에 표시됩니다.** 채우려는 채널을 사용할 수 없는 경우:

* 왼쪽 탐색 막대의 맨 아래에 있는 채널 설정 패널을 엽니다
* &quot;목록 편집&quot; 클릭
* 원하는 채널 활성화
* 채우기 필터 다시 적용 또는 업데이트

활성화되면 해당 채널을 적용 대상... 드롭다운에서 사용할 수 있습니다.

<b>기본 매개 변수</b>

채우기 필터 매개 변수 **적용 대상...에서 선택한** 채널 유형에 따라 동적으로 변경됩니다. 4개의 파라미터 세트가 존재하며, 각각은 특정 타입의 맵에 대응된다.

### 색상 맵 매개 변수

[칠] 필터를 색상 채널에 적용할 때 사용합니다.

#### 예제 채널:

* 기본 색상
* 코팅 색상
* 하위 표면 색상...

#### 사용 가능한 매개 변수

* 색상
채널을 채우는 데 사용되는 RGB 색상을 선택합니다.
* 사용자 정의 값
토글을 전환하여 사용자 정의 맵을 엽니다. 선택한 채널을 바꿀 이미지를 선택하거나 **2D 보기**&#x200B;에서 직접 칠하십시오.
* 임의 시드
절차 변형이 활성화된 경우 사용되는 임의화를 변경합니다.
* 혼합 모드
채우기가 아래 레이어와 혼합되는 방식을 결정합니다(예: 복사, 추가, 곱하기).
* 불투명도
기존 채널 정보를 기준으로 새 채널 정보의 불투명도를 조정합니다. 즉, 새 채널 칠을 적용하는 데 사용되는 마스크의 불투명도를 제어합니다.

이 모드는 일반적으로 색상 정보를 초기화 또는 재정의하는 데 사용됩니다.

### 그레이스케일 맵 매개변수

채우기 필터가 스칼라 회색조 채널에 적용될 때 사용됩니다.

#### 예제 채널:

* 반사 거칠기
* 기본 금속성
* 불투명도
* Height...

#### 사용 가능한 매개 변수

* 값
채널에 대한 단일 회색 음영 값을 설정합니다.
* 임의 시드
절차 변형이 활성화된 경우 사용되는 임의화를 변경합니다.
* 사용자 정의 값
토글을 전환하여 사용자 정의 맵을 엽니다. 선택한 채널을 바꿀 이미지를 선택하거나 **2D 보기**&#x200B;에서 직접 칠하십시오.
* 혼합 모드
복사, 추가(선형 닷지), 빼기, 곱하기, 하위 더하기, 최대(밝게), 최소(어둡게), 전환, 나누기, 오버레이, 화면, 소프트 라이트.
혼합 모드를 선택하여 사용자 정의 입력을 아래에 있는 레이어와 혼합합니다.
* 불투명도
기존 채널 정보를 기준으로 새 채널 정보의 불투명도를 조정합니다. 즉, 새 채널 칠을 적용하는 데 사용되는 마스크의 불투명도를 제어합니다.

이 모드는 일정한 거칠기 또는 불투명도 값과 같은 균일한 물리적 특성을 정의하는 데 유용합니다.

#### 표준 맵 매개 변수

칠 필터가 **표준** 채널에 적용될 때 사용됩니다.

##### 예제 채널:

* 표준
* 코팅 노멀

##### 사용 가능한 매개 변수

* 임의 시드
절차 변형이 활성화된 경우 사용되는 임의화를 변경합니다.
* 사용자 정의 값
토글을 전환하여 사용자 정의 맵을 엽니다. 선택한 채널을 바꿀 이미지를 선택하거나 **2D 보기**&#x200B;에서 직접 칠하십시오.
* 불투명도
기존 채널 정보를 기준으로 새 채널 정보의 불투명도를 조정합니다. 즉, 새 채널 칠을 적용하는 데 사용되는 마스크의 불투명도를 제어합니다.

이 모드는 주로 일반 정보를 재설정하거나 중화하거나, 일반 세부 정보를 추가하기 전에 깨끗한 기준선을 설정하는 데 사용됩니다.

### 균일 값 매개 변수

텍스처 맵이 아닌 하나의 균일한 실제 값에 의존하는 채널에 사용됩니다.

#### 예제 채널

* Specular...

#### 사용 가능한 매개 변수

* 임의 시드
절차 변형이 활성화된 경우 사용되는 임의화를 변경합니다.
* 값
채널에 적용되는 상수 값을 정의합니다.
* 혼합 모드
표준과 곱하기 사이

이 모드는 일부 속성이 맵이 아닌 스칼라 값으로 제어되는 템플릿을 통해 도입된 고급 재질 비헤이비어를 사용하여 작업할 때 특히 유용합니다.

## 일반적인 사용 사례

[칠] 필터는 일반적으로 다음 작업에 사용됩니다.

* 재질을 처음부터 만들 때 채널 초기화
* 기존 채널 값 재정의
* 균일한 물리적 특성(예: 고정된 거칠기 또는 금속성) 설정
* 세부 사항을 다시 작성하기 전에 [표준]과 같은 채널을 중화합니다
* 퍼지, 투명도 또는 코팅 값과 같은 고급 속성을 빠르게 조정할 수 있습니다

채우기 필터는 선택한 채널에 자동으로 적용되므로 모든 재질 유형에서 일관되고 예측 가능한 작업 과정을 제공합니다.
