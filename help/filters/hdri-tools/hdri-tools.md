# HDRI 도구

>[!IMPORTANT]
>
> 미래 변화
> 
> Sampler V5.2의 릴리스에서는 환경 조명 및 메시에 대한 지원이 제거됩니다. 환경 조명의 제거에는 HDRI 도구 및 필터 제거도 포함됩니다.

HDRI 도구 섹션의 필터는 환경 조명을 사용한 작업에 사용되는 도구입니다. HDRI는 High Dynamic Range 이미지 의 약어이지만, 일반적으로 환경 조명을 만드는 데 사용되는 파노라마 이미지를 나타내는 데 사용됩니다. 구형 3D 정보가 2D 이미지 파일에 매핑되는 방식 때문에 기존 소프트웨어에서 파노라마 이미지를 수정하는 것은 어려울 수 있습니다. Sampler의 HDRI 도구는 이러한 점을 염두에 두고 설계되었으므로 HDRI에 조명을 패칭하고 추가하는 것이 훨씬 쉬워졌습니다.
