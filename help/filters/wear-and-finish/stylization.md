## 설명

다양한 효과로 세부 사항을 단순화하기 위해 <b>스타일화 필터</b>를 사용하여 재질 모양을 수정할 수 있습니다.

아래 이미지는 [스타일화] 필터를 적용하기 전과 후의 나무껍질 재료를 보여줍니다.

## 사전 설정

<b>스타일화</b>

    기본 사전 설정은 작은 세부 사항은 흐리게 처리하고 대비는 높여 부드러운 스타일화 효과를 적용합니다

<b>대조된 스타일화</b>

    이 사전 설정은 재질에 브러시 스트로크 같은 효과를 적용합니다

<b>회화가</b>

    이 사전 설정은 재질에 흐릿하고 부드러운 브러시 스트로크 같은 효과를 적용합니다

<b>손으로 칠함</b>

    이 사전 설정은 이전 대비 방법보다 대비를 강하게 적용하며, 구아슈 또는 유화 페인트 수동 브러시 스트로크를 모방합니다

## 기본 매개 변수

* <b>임의 시드 </b>\
  이 필터의 다른 모든 임의 매개 변수가 기반으로 하는 임의 초기값입니다.

* <b>전역 필터 강도</b>: 0-1 \
  이 필터의 효과가 원본 재질에 적용되는 정도를 조정합니다. 전체 효과를 적용하려면 1로 설정합니다.

* <b>대비</b>: 0-1 \
  재질에 적용되는 대비 레벨 수정

* <b>색상 스타일화 강도</b>: 0-1 \
  필터의 스타일화 효과가 재질의 색상에 미치는 영향을 조정합니다

* <b>거칠음 스타일화 강도</b>: 0-1 \
  필터의 스타일화 효과가 재질의 거칠기에 미치는 영향을 조정합니다

* <b>금속 스타일화 강도</b>: 0-1 \
  필터의 스타일화 효과가 재질의 금속성에 미치는 영향을 조정합니다

* <b>Height 스타일화 강도</b>: 0-1 \
  필터의 스타일화 효과가 재질의 Height에 미치는 영향을 조정합니다

* <b>표준 스타일화 강도</b>: 0-1 \
  필터의 스타일화 효과가 재질의 표준에 미치는 영향을 조정합니다

## 기본 색상

* <b>색상화 강도</b>: 0-1 \
  더욱 선명한 색상

* <b>색상 입히기</b>: 색상 \
  &quot;색상화 강도&quot; 매개 변수의 영향을 받는 색상을 선택할 수 있습니다.

* <b>색상 변형 강도</b>: 0-1 \
  &quot;색상 변형&quot;에 정의된 색상의 영향을 받는 색상 강도를 조정합니다.

* <b>색상 변형</b>: 색상 \
  &quot;색상 변형 강도&quot; 슬라이더를 구동할 색상을 선택합니다.

* <b>색상 변형 대비</b>: 0-1 \
  &quot;색상 변형&quot;에 정의된 색상의 대비 조정

* <b>캐비티 색상 강도</b>: 0-1 \
  재료의 움푹 들어간 영역(&quot;캐비티 색상&quot;에 정의된 색상)에 나타나는 색상의 강도를 조정합니다

* <b>캐비티 색상</b>: 색상 \
  재질의 움푹 들어간 영역에 적용할 색상을 정의합니다

* <b>캐비티 범위</b>: 0-1 \
  재료의 오목 영역 너비를 정의합니다.

* <b>캐비티 흐림 효과</b>: 0-1\
  재질 캐비티의 가장자리에 있는 영역의 흐림 효과 레벨을 조정합니다

* <b>곡률 강도</b>: 0-1 \
  &quot;곡률 색상&quot; 매개변수에 정의된 색상으로 재료의 가장 높은 점이 표시되는 방법을 수정합니다

* <b>곡률 색상화 강도</b>: 0-1 \
  &quot;곡률 색상&quot; 매개변수에 정의된 색상의 불투명도를 조정합니다

* <b>곡률 색상</b>: 색상 \
  재질의 가장 높은 점에 적용할 색상을 정의합니다

* <b>곡률 흐림 효과</b>: 0-1 \
  &quot;곡률 색상&quot; 매개변수로 색상이 지정된 영역 주변의 흐림 효과 레벨을 조정합니다

## 그런지

* <b>그런지 강도</b>: 0-1 \
  재질 상단에 그런지 맵을 추가합니다. 그런지 맵은 아래에서 선택할 수 있습니다.

* <b>그런지 색상</b>: 색상 \
  선택한 그런지 맵을 적용하는 데 사용할 색상 선택

* <b>그런지 거칠음</b>: 0-1 \
  추가된 그런지 맵에 적용될 레벨 또는 거칠기를 조정합니다

* <b>그런지 금속</b>: 0-1 \
  추가된 그런지 맵에 적용될 금속 레벨 조정

* <b>그런지 거칠음 변형</b>: 0-1 \
  추가한 그런지 맵에 적용된 거칠기의 변형 레벨을 선택합니다

* <b>그런지 거칠음 변형 강도</b>: 0-1 \
  추가한 그런지 맵에 적용된 변형 강도의 변형 레벨을 선택합니다

* <b>그런지</b>: 이미지 \
  Sampler 에셋 라이브러리에서 그런지 맵으로 사용할 이미지 또는 [텍스처 생성기]를 선택합니다

## 기술 매개 변수

* <b>선명 효과 강도</b>: 0-1 \
  전체 선명하게 하기 효과의 강도 조정

* <b>선명 효과 반경</b>: 0-1 \
  전체 선명하게 하기 효과의 반경 조정

* <b>정상 다시 계산</b>: 전환 \
  Sampler이 재질에 적용된 변경 사항에 따라 표준을 다시 계산하도록 허용

* <b>표준 강도</b>: 0-1 \
  표준 맵의 강도 조정

* <b>표준 부드러움</b>: 0-1\
  재질을 더 부드럽게 만들기 위해 일반을 부드럽게 합니다

* <b>주변 오클루전 강도</b>: 0-1\
  AO 맵의 대비 수준 조정
