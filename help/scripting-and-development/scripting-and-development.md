# 스크립팅 및 개발

Adobe Substance 3D Sampler은 Sampler Python API를 통해 사용자 정의 플러그인을 지원합니다. 플러그인은 대형 재질 라이브러리를 위한 재질 제작 자동화부터, 새 설치를 위한 자동 설정 수행 또는 새 기능 추가에 이르기까지 모든 Sampler 사용자에게 유용할 수 있습니다.

Sampler을 설치하면 API에 대한 전체 설명서가 포함됩니다. Sampler 내에서 API 설명서를 열 수 있습니다.

* 도움말 > Python API 설명서... 를 사용하여 설명서를 엽니다.

* [설치된 플러그인 및 스크립트 관리](manage-installed-plugins-and-scripts.md)
* [Python 및 QML로 플러그인 만들기](create-a-plugin-with-python-and-qml.md)
* [Python으로 스크립트 만들기](../scripting-and-development/create-script-with-python/create-a-script-with-python.md)
