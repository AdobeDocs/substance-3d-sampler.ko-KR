# 시작 시 충돌 - 이전 OBS 버전

이전 [OBS](https://obsproject.com/fr) 버전이 설치되어 있어 시작할 때 응용 프로그램이 충돌할 수 있습니다.

이 문제를 해결하려면 [OBS 버전](https://obsproject.com/fr/download)을 업데이트하거나 제거하십시오.
