# 글꼴이 올바르게 표시되지 않음

Windows 10 Enterprise에서 [신뢰할 수 없는 글꼴 차단 기능](https://docs.microsoft.com/en-us/windows/security/threat-protection/block-untrusted-fonts-in-enterprise)을 사용하는 경우 이 [튜토리얼](https://www.tenforums.com/tutorials/139148-exclude-specific-apps-untrusted-font-blocking-windows-10-a.html)에 따라 글꼴 차단을 위해 신뢰할 수 없는 앱 목록에서 Sampler을 제외할 수 있습니다.
