# Substance 3D Sampler에서 Substance Alchemist 프로젝트 가져오기

버전 3.0.0부터는 이전 Substance Alchemist 프로젝트를 자동으로 사용할 수 없습니다. 이 페이지에서는 이러한 파일을 검색하는 방법에 대해 설명합니다.

## 1 - 실행 Substance Alchemist

1. Alchemist에서 원하는 프로젝트 열기
1. **파일** > **프로젝트 내보내기...**&#x200B;를 클릭합니다.
1. 프로젝트 위치를 선택하고 **확인**&#x200B;을 클릭하세요.

해당 작업 후에는 **종속성** 폴더가 있는 **.alch** 파일을 사용할 수 있습니다.

### 2 - Substance 3D Sampler 실행

1. **시작 화면**&#x200B;에서 **열기**&#x200B;를 클릭하세요.
1. **.alch** 파일이 있는 폴더로 이동합니다.
1. **.alch** 파일을 엽니다(**종속성** 폴더가 여전히 .alch 파일 옆에 있는지 확인).

모든 재질은 재질 섹션 아래의 프로젝트 패널에 나열됩니다.
