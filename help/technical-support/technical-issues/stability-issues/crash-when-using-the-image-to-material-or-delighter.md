# 이미지를 재료 또는 발신자에 사용할 때 충돌 발생

**Image To Material(AI 작동)** 및 **Delighter** 필터에는 사용 가능한 VRAM(최소 1GB)이 많이 필요합니다.

2GB의 VRAM만 사용할 수 있는 GPU 카드가 있고 2K/4K 해상도로 작업하는 경우 필터를 실행하기 위한 충분한 메모리를 할당할 수 없으며 충돌이 발생할 수 있습니다.
