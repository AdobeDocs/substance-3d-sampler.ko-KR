# 성능 모드

성능 모드는 해상도 제한, 그림자, 변위 품질 및 경로 추적과 같이 작업 과정 속도를 저하시킬 수 있는 모든 설정을 포함합니다. 필요 없는 기능을 끄고 특히 하드웨어가 가벼운 곳에서는 원하는 반응성을 얻으십시오.

>[!NOTE]
>
> 하드웨어가 Sampler의 [최소 요구 사항](../getting-started/system-requirements.md)을 충족하지 않는 경우 Sampler은 설정을 변경하는 옵션 없이 성능 모드처럼 작동하는 [낮은 사양 모드](low-spec-mode.md)에서 자동으로 실행됩니다.

## 성능 모드 전환

성능 모드는 **Sampler 창**&#x200B;의 오른쪽 상단에 있는 **성능 모드 단추**&#x200B;로 전환할 수 있습니다.

![](../assets/performance-mode-button.png)

## 성능 모드 설정 변경

**성능 모드 단추** 옆에 있는 드롭다운을 사용하여 성능 모드에서 사용할 수 있는 제한을 제어합니다.

![](../assets/performance-mode-settings.png)

| 설정 | 설명 |
| --- | --- |
| **최대 미리 보기 해상도** | 성능 모드는 미리 보기 해상도를 낮추어 렌더링 속도를 높입니다. 이렇게 해도 가져온 에셋이나 문서의 해상도는 변경되지 않습니다. 대신 뷰포트 렌더러의 품질이 변경됩니다. |
| **변위 품질 사용 안 함** | 이 설정을 사용하면 **성능 모드**&#x200B;에서 **변위 품질 값**&#x200B;을 0으로 잠가 뷰포트에서 변위 효과를 사용하지 않도록 설정합니다. 타일 또는 미세 직물과 같은 부드러운 재료의 경우, 이는 시각적 영향을 최소화하지만 실질적으로 성능을 향상시킬 수 있다. |
| **그림자 사용 안 함** | 망과 변위된 재질이 그림자를 드리울 수 있으므로 성능 저하로 보다 사실적인 이미지를 만들 수 있습니다. **그림자 비활성화**&#x200B;가 켜져 있으면 성능 모드는 모든 그림자 처리를 비활성화하여 성능을 향상시킵니다. |
| **경로 추적 사용 안 함** | 패스 추적은 밝은 패스가 장면을 통해 튕길 때 해당 패스를 따라 사용되어 사실적인 렌더링을 만드는 강력한 렌더링 방법입니다. 그러나 경로 추적은 비용이 많이 듭니다. **경로 추적 사용 안 함**&#x200B;이 켜져 있으면 성능 모드는 **3D 뷰포트**&#x200B;에서 경로 추적 사용 옵션을 비활성화합니다. |

>[!NOTE]
>
> 경로 추적은 **3D 뷰포트 도구 모음**&#x200B;에서 액세스할 수 있습니다.
>
> ![](../assets/enable-path-tracing.png)
>
> 경로 추적이 사용되지 않으면 **경로 추적 사용 안 함**&#x200B;만 켜고 켜는 성능 모드는 영향을 주지 않습니다.
