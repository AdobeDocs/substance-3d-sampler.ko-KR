# 업데이트 검사기

업데이트 창은 새 버전의 Substance Alchemist을 사용할 수 있는지 여부를 나타내며 최신 [릴리스 정보](../../release-notes/release-notes.md)도 표시합니다.

새 버전을 다운로드할 수 있는 경우 Substance Alchemist 시작 중에 이 창이 자동으로 나타납니다.

다음과 같은 방법으로 시작할 때 이 창이 표시되지 않도록 할 수 있습니다.

* 창에서 &quot;다음 버전까지 알림 안 함&quot; 설정을 사용하여 다음 버전까지 창 표시를 일시적으로 건너뜁니다.
* 편집 > 환경 설정 > 업데이트 확인에서 &quot;**업데이트 확인**&quot; 설정 사용 안 함
* 명령줄 **사용—skip-version-check** Substance Alchemist을 시작할 때 새 버전의 응용 프로그램을 사용할 수 있는지 확인하지 않습니다.
* 환경 변수 **SUBSTANCE\_ALCHEMIST\_SKIP\_CHECK\_FOR\_UPDATES**:Value 0 또는 1 사용(1 = 업데이트 확인 사용 안 함)

>[!NOTE]
>
> Substance Alchemist 2020.1(2.1) 이후 지원됨
