# 내보내기

**파일 메뉴**&#x200B;에서 **내보내기 형식**&#x200B;을 선택하거나 바로 가기 **Ctrl+E**&#x200B;을 사용하여 에셋을 내보낼 수 있습니다. 내보내기를 사용자 정의할 수 있는 [내보내기 창](../../getting-started/export/export-window/export-window.md)이 열립니다.

>[!NOTE]
>
> **내보내기 창**&#x200B;에서 재질 모델 옵션을 변경하면 내보낸 파일 이름이 선택한 재질 모델과 일치하도록 변경됩니다.

![재질 설정이 선택된 내보내기 창](../../assets/6.0_ExportWindowMaterialSettings.png)

Sampler은 에셋에 대한 주요 파일 포맷을 지원합니다.

* 재질은 **SBS** 또는 **SBSAR**&#x200B;파일로 내보낼 수 있습니다.
* 또는 다음 파일 포맷으로 채널별 비트맵 텍스처를 내보낼 수 있습니다.
  * **EXR**
  * **JPEG**
  * **PNG**
  * **TARGA**
  * **TIFF**
  * **USDA**
  * **USD**
  * **USDZ**

내보내기 사전 설정을 내보내고 관리하는 방법에 대해 자세히 알아보십시오.

* [내보내기 창](../../getting-started/export/export-window/export-window.md)
* [기본 사전 설정](../../getting-started/export/default-presets/default-presets.md)
* [사용자 정의 사전 설정 관리](https://helpx.adobe.com/substance-3d/unlisted/documentation/sadoc/creating-and-importing-custom-presets-188976295.html)
* [사전 설정 관리](managing-presets.md)
