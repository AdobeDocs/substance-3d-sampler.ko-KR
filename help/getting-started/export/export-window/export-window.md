# 내보내기 창

<b>오른쪽 표시줄</b>의 <b>내보내기</b> 패널에서 에셋을 내보낼 수 있습니다.

내보내기 옵션은 내보내는 에셋의 유형에 따라 달라집니다.

![내보내기 창의 이미지](../../../assets/6.0_ExportWindowMaterialSettings.png)

재료 내보내기를 위한 내보내기 창.

>[!NOTE]
>
> [내보내기] 패널에는 에셋을 Substance 3D Designer, Painter 또는 Stager로 보내는 옵션도 있습니다. 이렇게 하면 다른 Substance 3D 애플리케이션에 대해 올바른 설정을 사용하여 에셋을 자동으로 내보냅니다.

## 일반 설정

다음 설정은 모든 에셋 유형에 사용할 수 있습니다.

* <b>이름: </b>이 필드는 내보내는 에셋의 이름을 정의합니다. 내보낸 파일의 파일 이름에 접두어로 사용됩니다.
* <b>저장 위치: </b>에셋의 내보내기 대상을 선택합니다. 필요한 경우 선택한 위치에 하위 폴더를 만들 수도 있습니다. 이 옵션이 활성화된 경우 하위 폴더의 이름은 에셋의 이름을 따릅니다.

## 재질 설정

재질을 내보낼 때 내보내기 창의 재질 설정 패널에는 다음과 같은 옵션이 있습니다.

* <b>형식</b>: 내보낸 자산에 대한 파일 형식을 선택합니다.
  * <b>SBSAR</b>: Substance 재질을 지원하는 모든 응용 프로그램에서 사용할 수 있도록 재질을 내보냅니다.
  * <b>SBS</b>: Substance 3D Designer에서 열 수 있도록 자료를 내보냅니다.
  * <b>EXR, JPEG, PNG, TARGA, TIFF</b>: 재질을 이미지 파일의 컬렉션으로 내보냅니다.

>[!NOTE]
>
> 비트 심도가 일반 및 Height 채널에 대해 16비트로 강제 설정됩니다. 다른 채널은 에셋에서 사용하는 재질 및 필터에 따라 8/16비트로 내보내집니다. 일부 파일 형식은 높은 비트 심도를 지원하지 않으므로 파일 형식에 따라 비트 심도가 변경될 수 있습니다.

![](../../../assets/export-format.png){width="400px"}

* <b>사전 설정 </b>(EXR, JPEG, PNG, TARGA, TIFF): 사전 설정을 선택하여 지정된 응용 프로그램 또는 파이프라인에 대한 파일 내보내기를 자동으로 설정합니다.
  * <b>기본(프로젝트 워크플로)</b> 옵션은 사전 설정이 적용되지 않은 자료의 사용 가능한 모든 채널 목록을 표시합니다.
  * 사전 설정 매개 변수의 오른쪽에 있는 <b>사전 설정 관리 </b> 단추를 사용하여 사전 설정을 편집하거나 직접 추가합니다.<b> </b>
  * [사전 설정에 대한 자세한 내용은 여기에서 확인할 수 있습니다.](../managing-presets.md)

>[!NOTE]
>
> 내보내기 형식이 SBS 또는 SBSAR인 경우 사전 설정 선택을 사용할 수 없습니다. 이러한 포맷의 경우 출력 파일을 모든 Substance 제품 및 Substance 통합에서 사용할 수 있도록 이미 설정되어 있습니다.

* <b>재질 유형 </b>(SBSAR, SBS): 내보낸 재질이 표준 재질, 데칼 또는 지도형처럼 동작하는지 여부를 선택합니다. 이 설정은 SBSAR 및 SBS 파일을 지원하는 다른 응용 프로그램에서 이를 처리하는 방법을 변경할 수 있습니다.

![](../../../assets/screenshot-2023-01-24-at-16-32-58.png)

* <b>압축 </b>(SBSAR, SBS): 내보낸 파일의 압축 방법 선택
  * <b>자동</b>: Sampler에서 압축 설정을 확인하도록 허용합니다.
  * <b>최적</b>: 이 옵션을 사용하면 파일 크기가 작아지지만 파일을 인코딩하거나 디코딩하는 동안 로드 및 저장 시간이 길어질 수도 있습니다.
  * <b>없음</b>: 압축을 사용하지 않으면 파일 크기는 커지지만 더 빠르게 로드하고 저장할 수 있습니다.
* <b>해상도(</b>SBSAR, SBS<b>)</b>: 재질의 출력 해상도를 선택합니다.
  * 기본적으로 해상도는 Sampler의 전역 매개 변수를 기반으로 합니다. 다른 해상도를 선택하면 Sampler에서 이 새 해상도로 모든 재질을 다시 계산합니다. 재질의 최종 모양에 영향을 줄 수 있습니다.

![](../../../assets/SAPR_ResolutionSBSAR.png)

* <b>해상도 </b>(이미지 형식): 각 레이어의 해상도를 개별적으로 내보낼 것인지 또는 모든 레이어를 균일한 크기로 내보낼 수 있도록 해상도를 재정의할 것인지 선택합니다. [모두 무시]를 선택한 경우에는 출력 해상도를 수정하는 옵션이 표시됩니다.
  * 기본적으로 해상도는 각 레이어의 출력 해상도를 기반으로 합니다. 다른 해상도를 선택하면 Sampler에서 이 새 해상도로 모든 재질을 다시 계산합니다. 재질의 최종 모양에 영향을 줄 수 있습니다.

![](../../../assets/SAPR_ResolutionTextures.png)

* **재질 모델**(기본 사전 설정에 있는 모든 형식): 내보낸 텍스처에 대한 셰이더 표준을 선택합니다.
  * 재질 모델을 변경하면 내보낸 파일의 파일 이름에 영향을 줍니다. 예를 들어 OpenPBR은 &quot;Metallic&quot;을 사용하는 ASM과 반대로 &quot;Metalness&quot;를 사용합니다.

### 추가 정보

선택한 대상 드라이브의 사용 가능한 디스크 공간은 <b>내보내기 창</b>의 아래쪽에 표시됩니다.

>[!NOTE]
>
> <b>물리적 크기</b>은(는) 재질 생성 중에 설정되며 내보내기 중에 수정할 수 없습니다.

### 채널

![](../../../assets/SAPR_Channelspreview.png)

<b>재질 설정 패널</b>의 오른쪽에는 내보낼 수 있는 채널 및 해당 해상도의 목록이 표시됩니다(기본 채널 및 사용자 지정 채널).

각 사전 설정에는 내보낼 채널 집합이 서로 다르며, 내보낸 파일의 이름은 <b>내보낼 채널</b> 영역에 표시되는 이름을 기반으로 합니다. 모든 채널 옆의 확인란을 사용하여 해당 채널에 대한 내보내기를 활성화하거나 비활성화할 수 있습니다.
