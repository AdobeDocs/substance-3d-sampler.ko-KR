# 사전 설정 관리

사전 설정을 사용하면 내보낸 파일을 지정된 응용 프로그램에 맞게 빠르게 구성할 수 있습니다. 또한 기본 사전 설정이 적용되지 않는 파이프라인을 사용하는 경우 사용자 정의 사전 설정을 만들어 요구 사항을 충족할 수 있습니다.

## 사전 설정 사용

사전 설정은 이미지 파일로 내보낼 때만 사용할 수 있습니다. SBS 또는 SBSAR로 내보낼 때 사전 설정이 필요하지 않습니다.

사전 설정에 액세스하려면 다음을 수행합니다.

1. <b>내보내기 </b> 창 열기:
   1. <b>오른쪽 표시줄</b>에서 <b>내보내기 패널</b>을 사용합니다.
   1. <b> 파일 > 내보내기 형식...</b> 사용
   1. 바로 가기 <b>Ctrl + E.</b> 사용
1. <b>내보내기 </b>창의 왼쪽에서 <b>재질 설정</b>을 선택합니다.
1. 이미지 형식(EXR, JPEG, PNG, TARGA, TIFF) 선택
1. [사전 설정] 목록이 나타납니다.

![](../../assets/Managing-presets-Dropdown.png.img.png){width="400px"}

사전 설정 드롭다운을 사용하여 사전 설정을 선택하거나 드롭다운 옆에 있는 <b>사전 설정 관리 </b> 버튼을 사용하여 사전 설정을 관리합니다.

## 사전 설정 관리

사전 설정 드롭다운을 사용하여 사전 설정을 선택하거나 드롭다운 옆에 있는 <b>사전 설정 관리 </b> 버튼을 사용하여 사전 설정을 관리합니다.

## 기본 사전 설정

![](../../assets/Managing-presets-Window.png.img.png){width="400px"}

모든 기본 사전 설정에 대해 활성화/비활성화할 수 있습니다. 기본 사전 설정이 비활성화된 경우 사전 설정 드롭다운 목록에 표시되지 않습니다.

기본적으로 모든 사전 설정은 활성화됩니다.

## 사용자 정의 사전 설정

사용자 정의 사전 설정을 활성화/비활성화할 수 있습니다. 사용자 정의 사전 설정이 비활성화된 경우 사전 설정 드롭다운 목록에 표시되지 않습니다.

다음을 수행할 수도 있습니다.

* <b>이름 바꾸기</b>: 인터페이스에서 사전 설정의 이름을 변경합니다.
* <b>바꾸기</b>: 사전 설정의 파일을 새 버전으로 변경합니다.
* <b>삭제</b>: 사전 설정을 삭제합니다.
