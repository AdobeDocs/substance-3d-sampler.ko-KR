# 단축키

이 페이지에는 사용 가능한 모든 키보드 단축키와 해당 동작이 나열됩니다.

## 전역 단축키

| *동작* | *Windows* | *MacOS* |
| --- | --- | --- |
| 실행 취소 | Ctrl + Z | ⌘ + Z |
| 다시 실행 | Ctrl + Shift + Z | ⌘ + Shift + Z |
| 저장 | Ctrl + S | ⌘ + S |
| 새로 저장 | Ctrl + Shift + S | ⌘ + Shift + S |
| 내보내기 | Ctrl + E | ⌘ + E |
| 3D 보기 전용 | 3 | 3 |
| 2D 보기 전용 | 2 | 2 |

## 3D 보기 단축키

| *동작* | *Windows* | *MacOS* |
| --- | --- | --- |
| 카메라 회전 | Alt + 마우스 왼쪽 버튼 또는 마우스 왼쪽 버튼 | Option + 마우스 왼쪽 버튼 또는 마우스 왼쪽 버튼 |
| 카메라 팬 | Alt + 마우스 가운데 또는 마우스 가운데 | Option + 마우스 가운데 또는 마우스 가운데 |
| 카메라 확대/축소 | Alt + 마우스 오른쪽 버튼 또는 마우스 휠 | Option + 마우스 오른쪽 버튼 또는 마우스 휠 |
| 초점 | F | F |
| 환경 회전 | Shift + 마우스 오른쪽 | Shift + 마우스 오른쪽 |
| 환경 가시성 | 1 | 1 |
