# 리소스 가져오기

Sampler에서는 이미지 및 Substance 파일과 같은 외부 리소스를 사용하여 프로젝트를 수정할 수 있습니다. 다음 옵션 중 하나를 사용하여 파일을 프로젝트로 가져옵니다.

* 파일 탐색기에서 Sampler 창으로 파일을 끌어다 놓습니다. 가져오기 처리 방법을 변경하는 옵션이 있는 가져오기 창이 나타납니다.

![](../assets/importing-resources-Importwindow.png)

* <b>왼쪽 막대</b>에서 <b>콘텐츠 가져오기 </b>버튼을 사용한 다음 <b>레이어 스택에서 가져오기</b> 또는 <b>에셋에서 가져오기</b>를 선택합니다. 두 옵션 모두 가져올 파일로 이동하여 선택할 수 있는 파일 탐색기를 엽니다.
  * <b>레이어 스택에서 가져오기</b>는 현재 프로젝트에 대한 파일을 가져옵니다.
  * <b>내 에셋에서 가져오기</b>는 모든 프로젝트에서 액세스할 수 있도록 파일을 가져옵니다.

![](../assets/Project_CreateNew.png)

* <b>레이어</b> 패널에서 레이어가 만들어지지 않은 경우 사용 가능한 링크를 사용하여 파일을 가져와 재질의 베이스로 만들 수 있습니다.

>[!NOTE]
>
> 리소스는 연결되어 있으며 가져오지 않습니다. 따라서 리소스 파일을 이동하거나 삭제하면 해당 리소스로 만든 자료나 콘텐츠가 영향을 받습니다. 따라서 Sampler Assets에 대한 전용 폴더를 사용하는 것이 좋습니다.
> 
> 기본적으로 Sampler에 포함된 에셋은 C:\Program Files\Adobe\Adobe Substance 3D Sampler\Resources\assets 아래에 저장됩니다.

## 지원되는 파일 형식

| 유형 | 설명 |
| --- | --- |
| <b>비트맵/이미지</b>(JPEG, PNG 등) | <b>레이어 </b> 패널 또는 이미지 입력을 허용하는 SBSAR 또는 필터 매개 변수로 비트맵을 끌어 놓거나 가져올 수 있습니다. |
| <b>Substance 패키지</b>(SBSAR) | SBSAR 파일을 <b>에셋 </b> 패널 또는 <b>레이어 </b> 패널로 가져올 수 있습니다. |
