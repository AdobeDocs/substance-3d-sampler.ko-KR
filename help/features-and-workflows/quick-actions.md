# 빠른 작업

![](../assets/Quactooltip.png)

빠른 작업은 몇 번의 클릭만으로 에셋을 만들거나 스택에 여러 개의 레이어를 추가할 수 있는 시스템입니다. 빠른 작업을 사용하여 에셋을 만들거나 프로젝트를 만들거나 기존 스택에 필요한 레이어를 추가합니다.

Sampler의 여러 위치에서 빠른 작업을 찾을 수 있습니다.

* [홈 화면](../interface/the-home-screen.md)
* [새 창 만들기](../getting-started/project-management.md)
* [빠른 작업 패널](../interface/panels/quick-actions-panel.md)

| 빠른 작업 이름 | 설명 | 레이어 |
| --- | --- | --- |
| 이미지를 재질로 변환 | 단일 이미지에서 필요한 모든 채널이 포함된 자료를 만듭니다. | Material AI 균일화에 이미지 입력 |
| 다중 각도 이미지를 재질로 변환 | 서로 다른 조명 각도에서 촬영한 표면 사진을 병합하여 재질 만들기 | 입력 다중 각도를 자료로 균일화 |
| 텍스처 가져오기 | 텍스처 맵에서 재질을 만듭니다. | 입력 |
| 이미지 가져오기 | 빈 재질을 만들고 단일 이미지를 레이어로 추가합니다. | 입력 |
| 이미지를 자수로 변환 | 단계적 필터를 적용하여 이미지가 자수 패치처럼 보이게 하세요. | 투입 자수 |
| 섬유 재질 만들기 | 단계적 필터로 직물 재질을 만듭니다. | 헝겊 위브 |
| 이미지 조정 | 필터를 선택하여 재질에서 사용할 이미지를 미세 조정하고 준비하세요. | 입력 자르기 타일링 밝기/대비 색조/채도 색상 대체 |
| 비어 있는 재질 만들기 | 채널이 없는 재질을 만듭니다. | 없음 |

## 빠른 작업 사용 방법

<b>홈 화면에서</b>

빠른 작업을 클릭합니다.

![](../assets/clickquickaction-ezgif.com-video-gif-converter.gif)

또는 빠른 작업에 이미지를 드래그하여 놓습니다.

![](../assets/dndquickaction-ezgif.com-video-gif-converter.gif)

또는 빠른 작업에 이미지를 드래그하여 놓습니다.

<b>새로 만들기</b>에서

빠른 작업 또는 파일 가져오기를 선택하고 입력에 사용할 수 있는 빠른 작업을 확인합니다

![](../assets/createnew-1.png)

<b>빠른 작업 패널</b>에서

빠른 작업을 클릭하여 스택에 추가하거나 빠른 작업 유형에 따라 새 에셋을 만듭니다.

* <b>적용 :</b> 활성 스택에 빠른 작업을 적용합니다.
* <b>설치 :</b> 설치 창을 열어 빠른 작업을 스택에 추가하기 전에 미리 정렬합니다.
* <b>새 에셋 만들기 :</b> 선택한 빠른 작업으로 새 에셋을 만듭니다.
* <b>새 프로젝트 만들기 : </b>선택한 빠른 작업으로 새 프로젝트를 만듭니다.
