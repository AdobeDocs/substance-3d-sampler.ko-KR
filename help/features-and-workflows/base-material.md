# 기본 재질

**기본 재질**&#x200B;은(는) Sampler에서 재질을 만들 때 빠르고 유연한 시작점을 제공하도록 디자인된 기본 재질 레이어입니다. 이 옵션은 재질(OpenPBR 또는 ASM)에서 사용하는 **재질 모델**에 자동으로 적용되는 포괄적인 매개 변수 집합을 노출하므로 단순한 표면에서 복잡하고 물리적으로 풍부한 재질에 이르기까지 모든 항목을 빌드할 수 있습니다.
사전 설정에서 시작하든 처음부터 재질을 구축하든 상관없이 기본 재질을 통해 항상 **명확하고 예측 가능하며 편집 가능한 파운데이션**&#x200B;에서 시작할 수 있습니다.

## 재질 모델 인식(OpenPBR 및 ASM)

기본 재질이 **재료-모델 인식**입니다.
즉, 사용 가능한 속성과 기본값은 재질이 다음을 사용하여 생성되는지 여부에 따라 변경됩니다.

* OpenPBR
* ASM (Adobe 표준 재질)

두 버전 모두 같은 용도로 사용되지만 기본 재질 모델과 일치하는 **다른 매개 변수 그룹 및 동작**&#x200B;을 노출합니다.

### OpenPBR 기본 재질

매개 변수 그룹에는 다음이 포함됩니다.

* 기본
* 반사
* 전송
* 표면 아래
* 코팅
* 퍼즈
* 방출
* 박막
* 기하학
* 기타

이러한 매개변수는 OpenPBR의 통합된 물리적 기반 표현에 맞춰 조정되며 광범위한 3D 에코시스템 전반의 상호 운용성을 위해 설계되었습니다.

### ASM 기본 재질

매개 변수 그룹에는 다음이 포함됩니다.

* 표면
* 흡수
* 분산
* 반투명도
* 코팅
* 광택
* 방출
* 기하학

이 레이아웃은 ASM 음영 모델을 미러링하며 기존 ASM 기반 워크플로우와의 연속성을 보장합니다.

>[!NOTE]
>
>기본 재질은 적용되는 재료의 재질 모델에 항상 적응합니다. OpenPBR 재질에 적용된 기본 재질은 ASM 매개변수를 표시하지 않으며 그 반대의 경우도 마찬가지입니다.

## 균일 값 및 사용자 정의 맵

노출된 모든 매개 변수에 대해 기본 재질은 두 가지 작업 방식을 제공합니다.

### 균일 값(기본값)

기본적으로 매개 변수에는 균일 값(슬라이더 또는 색상 피커)이 사용됩니다.
그러면 텍스처 입력 없이 재질의 전체 모양을 빠르게 정의할 수 있습니다.

균일 값은 다음에 적합합니다.

* 재질 차단
* 깨끗하고 단순한 표면 만들기
* 시각적 시작점 설정

### 사용자 정의 맵

텍스처 맵이 이미 있는 경우 **사용자 지정 맵 입력**&#x200B;을 활성화하여 **모든 균일 값을 재정의**&#x200B;할 수 있습니다.

* 매개 변수의 사용자 정의 맵 옵션 전환
* 기존 텍스처 연결
* 균일 값이 맵으로 완전히 바뀝니다

## 사전 설정

이 기본 재질은 속성 패널 상단에 축소판으로 표시되는 **사전 설정** 세트를 포함합니다.
사전 설정은 다음과 같습니다.

* 사전 구성된 기본 재질 값
* 시각적으로 의미 있는 설정에서 빠르게 시작하는 방법
* 공통적인 표면 유형을 위한 일관되고 읽기 쉬운 시작점

사전 설정을 선택해도 재질이 잠기지 않습니다. 모든 매개 변수는 완전히 편집 가능한 상태로 유지됩니다.

## 재질을 만들 때 &quot;사전 설정 값 적용&quot;

새 재질을 만들 때 [새 재질 만들기] 패널에서 사전 설정 값을 적용하도록 선택할 수 있습니다.
기능

* 기본 재질의 기본값을 선택한 사전 설정 축소판이 나타내는 값으로 바꿉니다
* 중립 기본값 대신 즉시 시각적 시작점을 제공합니다.
* 새 재질을 시작할 때 &quot;빈 페이지&quot; 효과를 줄이는 데 도움이 됩니다.

도움이 되지 않는 기능

* 값이 베이킹되거나 고정되지 않습니다
* 더 이상 편집할 수 없습니다
* 텍스처 맵이 자동으로 추가되지는 않습니다

갈 수 있는 곳을 제한하는 것이 아니라 출발하는 곳을 선택하는 것으로 생각할 수 있다.

## 채널 활성화: 중요한 단계

기본 재질 매개 변수가 눈에 보이는 효과를 주려면 재질의 채널 설정에서 해당 채널을 활성화해야 합니다.

### 모범 사례

매개 변수를 변경하기 전에 해당 채널이 활성화되었는지 확인합니다
재료를 깨끗하고 효율적으로 유지하는 데 필요한 채널만 활성화합니다
