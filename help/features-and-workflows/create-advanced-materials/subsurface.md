# 서브서피스 채널을 사용한 작업

서브표면 채널은 불투명하지만 반투명한 재료에 대해 유용하며, 재료의 표면 아래로 광이 산란되는 효과를 모방한다. 이 효과는 일반적으로 피부, 나뭇잎 및 많은 플라스틱과 같은 재질에서 발생합니다. 아래 비디오를 통해 밑면 매개 변수에 대해 자세히 알아보고 수지 재질을 만드는 데 사용하십시오.
