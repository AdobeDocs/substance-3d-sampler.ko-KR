# 코팅 채널을 사용한 작업

이름에서 알 수 있듯이 코팅 채널을 사용하면 재료에 코팅을 추가할 수 있습니다. 코팅은 고유의 거칠기 값을 가질 수 있으며, 이는 재료의 베이스 거칠기에 영향을 미쳐 바니쉬화되거나 연마된 표면과 같은 효과를 생성하는 데 도움이 될 수 있다. 아래 비디오를 통해 Sampler의 코팅 채널을 사용하여 처음부터 광택 있는 쪽매 바닥 재질을 만드는 방법을 알아보십시오.
