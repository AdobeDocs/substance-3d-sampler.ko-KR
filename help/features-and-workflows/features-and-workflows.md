# 기능 및 작업 과정

Sampler은 기존 에셋에서 세부적인 재질을 빠르게 제작할 수 있는 훌륭한 도구이지만, [이미지에서 재질로]와 같은 워크플로우를 통해 Sampler을 독창적으로 만들 수 있습니다.

이 섹션에서 다음 도구 및 작업 과정을 사용하는 방법에 대해 알아보십시오.

* 이미지를 재질로
* 엔드투엔드 물리적 크기 워크플로우
* 파라메트릭 에셋 내보내기 방법
* [텍스처 생성기](texture-generators.md)
