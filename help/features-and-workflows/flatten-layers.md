# 레이어 병합

레이어 병합은 성능을 향상시키고 레이어 스택을 단순화하는 데 도움이 되는 방법이지만, 레이어 병합이 프로젝트에 미칠 수 있는 영향에 대해 인지하는 것이 중요합니다.

## [레이어 병합] 버튼은 어떤 작업을 하나요?

레이어 병합 기능을 사용하면 현재 선택한 레이어의 모든 레이어가 단일 레이어로 병합됩니다. 병합된 레이어는 원본 레이어와 모양이 동일하지만 원본 개별 레이어를 더 이상 조정할 수 없습니다.

### 레이어를 병합하는 이유는 무엇입니까?

레이어 스택에서 레이어를 변경할 때마다 Sampler은 해당 레이어와 그 위에 있는 모든 레이어의 출력을 다시 계산해야 합니다. 계산할 각각의 추가 계층은 추가적인 처리 시간 및 메모리 사용량을 의미한다. 여러 레이어를 병합하면 해당 레이어를 처리하는 데 필요한 시간과 메모리가 줄어듭니다. 예를 들어 10개의 레이어를 다시 계산하지 않고 Sampler에서 단일 레이어만 처리하면 됩니다.

또한 레이어를 병합하면 레이어 스택이 단순해져 보다 쉽게 탐색하고 이해할 수 있습니다.

### 레이어를 병합해야 하는 경우는 언제입니까?

병합된 레이어는 레이어 스택에서 개별적으로 액세스할 수 없으므로 병합된 결과에서 매개 변수를 변경할 수 없습니다. 결과적으로 해당 레이어의 결과를 더 이상 변경할 필요가 없는 경우에만 레이어를 병합해야 합니다.

## 병합 레이어 매개 변수

원본 레이어의 매개 변수는 손실되지만 [병합 레이어]에는 각 결과 채널이 사용되는 방식을 제어하기 위해 조정할 수 있는 자체 매개 변수 세트가 있습니다.

각 채널에 대해 다음을 수행할 수 있습니다.

* <b>출력 사용</b>: 출력을 사용하는 채널을 변경합니다. 레이어를 병합하면 TIFF이 만들어지고 각 채널에 대해 이름이 지정되며 해당 채널에 자동으로 할당됩니다.
* <b>알파 채널의 불투명도</b>: 불투명도가 Alpha 채널 결과를 기반으로 하는지 여부를 전환합니다.
* <b>제거</b>: 이 레이어에서 채널을 제거합니다. 이 옵션은 유용한 정보가 없는 채널에 유용할 수 있습니다. 예를 들어 흰색 불투명도 채널을 모두 제거하는 것이 좋습니다. 이렇게 하면 시각적 결과에 영향을 주지 않고 메모리를 확보할 수 있습니다.
