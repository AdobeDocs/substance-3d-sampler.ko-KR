# 환경 변수

이 페이지에는 애플리케이션의 기본 동작을 재정의하는 데 사용할 수 있는 환경 변수가 나열됩니다.

| 변수 | 설명 |
| --- | --- |
| **SUBSTANCE\_SAMPLER\_라이선스** | 값: license.key 파일의 경로애플리케이션이 라이선스 파일을 로드하는 위치를 재정의합니다.  **참고:** 3.0 이전 버전에서는 이 변수 이름을 대신 사용합니다.**SUBSTANCE\_ALCHEMIST\_라이선스** |
