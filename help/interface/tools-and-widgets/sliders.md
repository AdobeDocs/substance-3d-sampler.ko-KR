# 슬라이더

![](../../assets/sliders-basic.gif)

한 슬라이더에서 여러 슬라이더까지 애니메이션화하는 옵션이 있습니다. 슬라이더를 가리킬 때 **Ctrl**&#x200B;을 누르면 **재생** 아이콘이 표시되어 애니메이션을 시작합니다.

**Ctrl**&#x200B;을 눌러 애니메이션을 일시 중지할 수 있습니다. 애니메이션 슬라이더를 가리킬 때 **일시 중지** 아이콘이 표시되어 이 슬라이더의 애니메이션을 중지합니다.

모든 슬라이더를 일시 중지하려면 **P**&#x200B;를 누르세요. 다시 실행하려면 **P**&#x200B;를 다시 누릅니다.
