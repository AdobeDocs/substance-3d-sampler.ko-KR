# 인터페이스

Sampler의 작업 영역은 2D 및 3D 뷰포트, 왼쪽 및 오른쪽 사이드바, 패널 모음으로 구성되어 있습니다. 각 패널은 특정 목적에 따라 전용으로 사용되므로 창작 과정의 각 부분에 서로 다른 패널이 유용합니다.

## 작업 영역 개요

작업 영역은 Sampler에서 대부분의 시간을 보낼 수 있는 곳입니다. 기본적으로 작업 영역은 6개의 영역으로 구성됩니다.</td>
<td style="border: 0;" valign="top">

![Sampler 인터페이스를 보여 주는 다이어그램](../assets/Interface-overview-diagram.png){zoomable="yes"}

</td>
</tr>

A. <b>응용 프로그램 메뉴 모음</b>에 현재 프로젝트 이름이 표시됩니다. 또한 파일, 편집, 창, 도움말 및 라이선스 메뉴도 있습니다.\
B. **왼쪽 사이드바**&#x200B;에서 다음을 수행할 수 있습니다.

* 콘텐츠를 추가 및 가져옵니다.
* Creative Cloud 데스크탑에서 3D 에셋을 검색합니다.
* 빠른 작업에 액세스합니다.
* 공통 도구에 빠르게 액세스합니다.
* **채널 설정 패널**&#x200B;을 엽니다.

C. <b>프로젝트</b> 및 <b>에셋 패널.</b>
D. <b>2D </b>및 <b>3D 뷰포트</b>에 현재 작업 중인 에셋이 표시됩니다.\
E. <b>레이어</b> 및 <b>속성 패널.</b>
F. **오른쪽 사이드바**&#x200B;에서 다음 패널에 액세스할 수 있습니다.

* 표시된 파라미터
* 실제 크기
* 메타데이터
* 내보내기

<b>응용 프로그램 메뉴</b>에 대한 자세한 내용은 아래에서 확인할 수 있습니다. **[패널](panels/panels.md)**, **[뷰포트](2d-and-3d-viewport.md)** 및 **[사이드바](sidebars.md)**&#x200B;에는 각각 자체 문서가 있습니다.

## 작업 영역 사용자 정의

Sampler의 작업 영역은 완전히 사용자 정의할 수 있으므로 사용자에게 가장 적합한 레이아웃을 찾을 수 있습니다. 패널을 기본 레이아웃으로 재설정하려면 **창 > 기본 레이아웃으로 재설정**&#x200B;을 사용하십시오.

## 패널 재정돈

패널의 제목을 클릭하고 드래그하여 이동을 시작합니다.

뷰포트 또는 다른 패널의 가장자리에 패널을 고정할 수 있습니다. 패널을 고정할 가장자리 위로 드래그하면 파란색 강조 가이드가 나타납니다. 선이 표시되면 패널을 놓아 고정시킵니다.

## 패널 열기 및 닫기

패널의 오른쪽 상단에 있는 X 를 사용하여 닫습니다. 닫힌 패널은 사이드바에 저장됩니다.

패널을 다시 열려면 왼쪽 또는 오른쪽 사이드바에서 패널에 대한 관련 아이콘을 클릭합니다. 그러면 패널이 일시적으로 열립니다. 패널을 밖으로 드래그하여 패널을 계속 열어 놓습니다.

## 응용 프로그램 메뉴

**응용 프로그램 메뉴 모음**&#x200B;에 현재 프로젝트 이름이 표시됩니다. 또한 **파일**, **편집**, **창**, **도움말** 및 **라이선스** 메뉴도 있습니다.

<b>파일</b> 메뉴를 사용하여 새 프로젝트를 만들거나, 기존 프로젝트를 열거나, 현재 프로젝트를 저장하거나 내보냅니다.

<b>편집</b> 메뉴를 사용하여 동작을 실행 취소하고 다시 실행하거나 [환경 설정](../interface/preferences/preferences.md)을 엽니다.

<b>창</b> 메뉴를 사용하여 작업 영역을 기본 레이아웃으로 다시 설정합니다.

<b>도움말 </b>메뉴를 사용하여 Sampler에 대해 자세히 알아보거나 문제를 해결하는 방법을 알아보십시오.

| 도움말 메뉴 항목 | 설명 |
| --- | --- |
| 튜토리얼 | Sampler 튜토리얼 페이지를 엽니다. Tutorials은 Sampler 사용의 기본 사항부터 작업을 가속화할 수 있는 고급 기술까지 모든 것을 다룹니다. |
| 설명서 | 자세한 내용은 설명서를 참조하십시오. 이 설명서에서는 Sampler 사용의 모든 측면에 대한 정보를 제공합니다. |
| Python API 설명서 | Sampler의 Python API를 사용하여 작업을 자동화하는 방법에 대해 알아봅니다. |
| 키보드 단축키 | 키보드 단축키의 전체 목록을 확인하십시오. 단축키를 사용하면 커서에만 의존하는 것보다 더 빠르게 작업할 수 있습니다. |
| 시작 | <b>시작 창</b>을 열어 Sampler에서 가능한 작업에 대해 자세히 알아보십시오. |
| 새로운 기능 | <b>새로운 기능 창</b>을 열어 최신 Sampler 릴리스에서 변경된 내용을 확인합니다. |
| 릴리스 정보 | 최신 버전의 Sampler에서 변경된 내용을 확인해 보십시오. |
| 포럼 | 포럼을 열어 Substance 3D Sampler 커뮤니티의 다른 멤버와의 대화에 참여하거나 나만의 게시물 및 제안을 제출하십시오. |
| 버그 보고 | Sampler의 문제를 보고하십시오. |
| 로그 내보내기 | 이 기능은 Sampler 사용 중에 발생할 수 있는 문제를 해결하는 데 유용할 수 있습니다. |
| Substance 3D 에셋 | Substance 3D 팀이 만들고 선별한 방대한 자료 및 기타 에셋 라이브러리에 액세스하려면 Substance Source을 여십시오. |
| Substance 3D 커뮤니티 에셋 | Substance 3D 커뮤니티 멤버들이 제작한 재질 라이브러리 및 기타 에셋에 액세스하려면 Substance share을 엽니다. |
| 하드웨어 정보 | 장치 하드웨어에 대한 정보를 확인하십시오. |
| Sampler 정보 | 설치된 버전의 Sampler에 대한 정보를 확인하십시오. |

**라이선스** 메뉴에서 내 계정 관리를 사용하여 Adobe 계정에 액세스하세요. 로그아웃을 클릭하여 Adobe 계정에서 로그아웃합니다.
