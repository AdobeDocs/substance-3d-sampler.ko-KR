# 노출된 파라미터 패널

![](../../assets/ezgif-com-gif-maker-7.gif)

**노출된 파라미터 패널**&#x200B;에는 **속성 패널**&#x200B;에서 노출된 매개 변수가 있습니다.

색상이 있는 점은 매개 변수가 연결된 레이어를 시각화하는 데 도움이 됩니다. 빈 점은 매개 변수가 블렌드 레이어에서 왔음을 나타냅니다.

![](../../assets/ezgif-com-gif-maker-1.gif)

다음 몇 가지 방법으로 노출된 매개 변수와 상호 작용할 수 있습니다.

| 액션 | 방법 |
| --- | --- |
| 매개 변수 노출 취소 | 매개 변수를 마우스 오른쪽 버튼으로 클릭하고 &quot;Unexpose&quot;를 선택합니다. |
| 매개 변수의 레이블 편집 | 매개 변수를 마우스 오른쪽 버튼으로 클릭하고 &quot;편집&quot;을 선택한 다음 새 레이블을 입력합니다. |

일반적으로 **속성 패널**&#x200B;과 같은 방법으로 모든 매개 변수와 상호 작용할 수 있습니다. 변경 내용은 3D 뷰포트에 반영됩니다.
