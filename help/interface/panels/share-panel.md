# 내보내기 패널

<b>내보내기 패널</b>에서 에셋을 일반 파일로 내보내거나 에셋을 다른 애플리케이션으로 직접 보낼 수 있습니다.

## 다음으로 보내기...

보내기... 옵션을 사용하면 에셋을 시스템에 설치된 다른 애플리케이션으로 직접 보낼 수 있습니다. 일반적으로 에셋 가져오기 및 내보내기보다 훨씬 빠릅니다.

현재 Sampler에서는 다음으로 전송을 지원합니다.

* **Substance 3D Painter**: 에셋을 텍스처링하는 동안 사용할 수 있는 재질 및 환경을 가져옵니다.
* **Substance 3D Stager**: 환경 조명을 가져와 장면의 분위기를 변경합니다. 환경 조명에서만 사용할 수 있으며 재질에 대해서는 비활성화됩니다.

재질은 항상 SBSAR로, 환경은 EXR로 전송됩니다.

## 내보내기

**내보내기 형식...**&#x200B;을 클릭하여 현재 작업 중인 에셋을 내보냅니다. 왼쪽 메뉴에서 [일반] 설정을 수정할지, [재질] 설정을 수정할지 선택합니다.

### 일반 설정

[일반 설정]을 선택한 상태에서 재질 이름과 저장 위치를 변경할 수 있습니다. 재질의 하위 폴더를 만들지 여부를 토글할 수도 있습니다. 이 기능은 여러 파일을 만드는 이미지 형식으로 내보낼 때 유용합니다.

### 재질 설정

재질 설정을 선택한 상태에서 다양한 매개 변수를 변경하여 재질을 내보내는 방법을 제어할 수 있습니다.

| 설정 | 설명 |
| --- | --- |
| 형식 | SBS, SBSAR 또는 특정 이미지 형식의 이미지 모음으로 내보내는지 여부를 선택합니다. |
| 사전 설정 | 사전 설정을 선택하여 특정 애플리케이션에 대한 내보내기를 자동으로 구성합니다. [사전 설정에 대한 자세한 내용은 여기에서 확인할 수 있습니다](../../getting-started/export/default-presets/default-presets.md). 사전 설정은 이미지 포맷을 선택한 경우에만 사용할 수 있습니다. |
| 압축 | 압축이 <br> 속도 또는 효율의 우선 순위를 지정하는지 여부 선택 <ul> <li> **자동**: Sampler에서 선택할 수 있습니다. <li> **최고**: 작은 파일의 압축 효율을 극대화합니다. <li> **없음**: 압축이 없으면 내보낸 파일을 더 빨리 열고 닫을 수 있지만 파일 크기가 더 커집니다. </ul> |
| 해결 방법 | 내보내기 해상도를 변경합니다. 이 옵션은 선택한 형식에 따라 다르게 나타납니다. <br> <ul> <li> **SBSAR/SBS**: 재질의 기본 폭과 Height을 선택합니다. 나중에 업데이트할 수 있습니다. <li> **이미지 형식**: 레이어 스택으로 정의된 크기로 각 맵을 내보내는 **레이어 출력** 또는 내보낼 폭과 Height을 지정할 수 있는 **모두 재정의** 중에서 선택합니다. |
| 재질 모델 | Adobe 표준 재질로 내보낼 것인지 또는 OpenPBR 재질로 내보낼 것인지 선택합니다. 선택하는 옵션은 파이프라인에서 사용 중인 다른 응용 프로그램에 따라 달라집니다. 재질 모델에 따라 다른 채널을 사용할 수 있습니다. |
| 채널 | 에셋의 일부로 내보낼 채널을 전환합니다. |

>[!NOTE]
>
> 내보내기 대화 상자 옵션 및 파일 형식과 같은 기타 정보에 대한 자세한 내용은 [내보내기 문서](../../getting-started/export/export.md) 및 [내보내기 창의 하위 문서](../../getting-started/export/export-window/export-window.md)를 참조하세요.

내보내기 설정이 만족스러우면 **내보내기**&#x200B;를 클릭하세요. 내보내기가 최근 내보내기 목록을 보여주는 내보내기 대기열에 표시됩니다. 내보내기에서 폴더 아이콘을 클릭하여 해당 내보내기의 파일 위치를 엽니다.
