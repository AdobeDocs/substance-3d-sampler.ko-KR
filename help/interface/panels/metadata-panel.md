# 메타데이터 패널

![](../../assets/Metadata-panel-gen.png){width="500px"}

메타데이터 패널에서 에셋의 메타데이터에 액세스하고 수정할 수 있습니다.

<b>이름</b>: 에셋의 이름입니다.

<b>설명</b>: 에셋에 대한 설명 또는 Substance 자료에 포함된 설명

<b>범주</b>: 에셋의 범주 또는 Substance 자료에 포함된 범주

<b>작성자</b>: 에셋 작성자 또는 Substance 자료에 포함된 작성자입니다. 기본적으로 작성자의 이름은 OS 계정의 이름입니다.

<b>만든 날짜</b>: Sampler에서 에셋을 만든 날짜 또는 Sampler으로 가져온 날짜 (편집할 수 없음)

<b>업데이트 날짜</b>: 에셋이 마지막으로 업데이트된 날짜입니다. (편집할 수 없음)

<b>태그</b>: 에셋의 태그나 Substance 자료에 포함된 태그입니다.

<b>물리적 크기</b>: 에셋의 X, Y 및 Z 크기.

<b>등급</b>: 에셋의 등급입니다.

## 사용자 정의 메타데이터

모든 사용자 정의 메타데이터가 재질 파일(SBSAR)에 포함되어 애플리케이션 간에 디지털 재질을 공유하는 보다 효율적인 작업 과정을 보장합니다.

![](../../assets/Metadata-panel-Custom.png){width="350px"}

<b>새 텍스트 필드 </b>(메타데이터용 사용자 지정 필드 추가):

1. 이름을 삽입합니다. 사용자 정의 메타데이터의 이름은 올바른 XML 요소 이름이어야 합니다(예: 공백이나 특수 문자가 없고 숫자로 시작하지 않음).
1. 설명/참고 삽입

필드 위에 커서를 놓고 표시되는 편집 또는 삭제 버튼을 선택하여 사용자 정의 메타데이터 필드를 수정합니다.
