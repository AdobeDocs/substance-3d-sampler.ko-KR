# 셰이더 설정 패널

![](../../assets/Shader-settings-panel-gen.png.img.png)

<b>셰이더 설정 패널</b>에서는 셰이더가 3D 뷰포트의 메시에서 에셋을 렌더링하는 방법을 구성할 수 있습니다.

## 재질 파라미터

질감 매개 변수를 사용하면 현재 질감이 셰이더에 의해 렌더링되는 방식을 조정할 수 있습니다.

| 매개 변수 이름 | 설명 |
| --- | --- |
| 법선 비율 | 표준 맵의 강도나 강도를 조정합니다. |
| 정상 및 높이 결합 | Height 맵과 표준 맵을 단일 맵으로 결합할지 여부를 전환합니다. |
| 높이 수준 | 변위에 대한 Height의 기본 수준을 변경합니다. |
| 방출 강도 | 방출 지도의 강도를 조정합니다. |
| 표면 하부 산란 | 서브서피스 스캐터링을 켜거나 끕니다. |
| 굴절 인덱스 | 빛이 표면에서 굴절되는 각도를 조정합니다. |
| 코팅 굴절 인덱스 | 빛이 표면 털에서 굴절되는 각도를 조정합니다. |
| 코팅 법선 비율 | 특히 표면 털에 대해 표준 비율을 조정합니다. |
