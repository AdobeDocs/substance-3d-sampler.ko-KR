# 프로젝트 패널

![](../../assets/Project-panel-gen.png)

Sampler의 프로젝트는 여러 에셋을 저장할 수 있는 패키지와 같은 역할을 합니다. **프로젝트 패널**&#x200B;에 현재 프로젝트를 구성하는 재질이 표시됩니다.

[프로젝트] 패널 상단의 컨트롤을 사용하면 현재 프로젝트에 재질을 추가하거나 관리할 수 있습니다.

* **추가** 단추를 사용하여 **재질 사전 설정 메뉴**&#x200B;를 열고 프로젝트에 새 재질을 추가합니다.
* **복제** 단추를 사용하여 현재 선택한 재질을 복제합니다.
* **이름 바꾸기** 단추를 사용하여 현재 선택한 재질의 이름을 바꿉니다.
* **삭제** 단추를 사용하여 현재 선택한 재질을 삭제합니다.

>[!NOTE]
>
> 재질을 마우스 오른쪽 버튼으로 클릭하여 이름을 바꾸거나 삭제하거나 복제할 수도 있습니다.

에셋 중 하나를 클릭하여 **뷰포트**&#x200B;에 로드하거나 재질을 **레이어 패널**&#x200B;로 드래그하여 다른 재질에 사용합니다.
