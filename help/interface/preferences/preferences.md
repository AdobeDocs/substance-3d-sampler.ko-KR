## 일반

* **인터페이스**
  * **언어**\
    Sampler은 현재 다음 UI 언어를 지원합니다.
    * 미국 영어
    * 프랑스어
    * 독일어
    * 일본어
    * 중국어 간체
    * 이탈리아어
    * 스페인어
    * 포르투갈어
* **프로젝트**
  * **일반 형식**\
    애플리케이션에 사용되는 표준 형식을 설정합니다.
  * **기본 레이어 해상도**\
    응용 프로그램에 사용되는 기본 해상도 전략을 설정합니다.
  * **기본 재질 모델**
    재료를 생성하거나 빠른 작업으로 재질 모델을 선택해야 하는 경우 사용할 기본 모델을 설정합니다.
  * **기본 질감 타일링 - U**\
    기본 U 텍스처 타일링을 설정합니다.
  * **기본 질감 타일링 - V**\
    기본 V 텍스처 타일링을 설정합니다.
  * **기본 Height 비율**\
    재질에 대한 기본 Height 비율을 설정합니다.
* **개인 정보**
  * **사용 통계를 자동으로 보내기**
    Sampler 개선에 도움이 되도록 익명화된 사용 통계를 보낼지 여부를 토글합니다.
* **색상 설정**
  * **실험적 별색 선택기**\
    색상 선택 매개 변수가 나타날 때마다 시험적 색상 피커를 활성화하거나 비활성화합니다. 시험적 색상 피커를 사용하면 PANTONE 색상 견본 컬렉션에서 직접 색상을 선택할 수 있습니다.
* **리소스**
  * **썸네일 품질**\
    에셋 패널에서 썸네일의 품질을 조정합니다. 썸네일 품질을 낮추면 썸네일 로드 시간이 단축됩니다.
* **상호 운용성**
  * **Designer 형식으로 보내기**\
    애플리케이션에서 Designer으로 전송하는 형식을 설정합니다.
    * **SBS**
    * **SBSAR**
* **머신 러닝**
  * **GPU 가속 신경망**\
    GPU 가속 Neural Networks를 활성화하거나 비활성화하여 응용 프로그램의 성능을 개선합니다.

### 스토리지 및 캐시

* **캐시**\
  이 설정을 사용하여 캐시 위치를 업데이트합니다.
  * 렌더링된 텍스처의 캐시 경로
  * 축소판 캐시의 경로입니다.
* **재질 캡처**\
  이 설정을 사용하여 재질 캡처 캐시 위치를 업데이트합니다.
  * 재질 캡처 캐시의 경로입니다.
  * Captis IP 주소\
    로컬 네트워크의 Captis 장치에 연결합니다.
  * Captis 장치를 복사된 파일에 대한 USB 저장소로 사용합니다.
* **프로젝트 파일에 포함된 캐시 저장소**\
  파일을 저장할 때 Sampler에서 캐시된 내용을 처리하는 방법을 변경합니다.

### 플러그인 및 스크립트

* **인터페이스**
  * **로그 패널 사용**\
    로그 패널을 활성화하거나 비활성화합니다. 활성화하면 **[오른쪽 사이드바](../sidebars.md)**&#x200B;에서 로그 패널을 열 수 있습니다.
* **플러그인 관리**
  * 플러그인 위치를 선택하고 새 플러그인을 가져온 다음 기존 플러그인을 활성화 또는 비활성화합니다.
* **스크립트 관리**
  * 스크립트 폴더 위치를 선택하고 스크립트를 가져옵니다.
